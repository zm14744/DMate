# 常见清晰图识别验收

本要求依据用户 2026-10-27 的最新说明，适用于后续版本验收。可视化编辑、确认后解题、最多四张原图独立并发继续保留；用户能修改错误不替代自动识别指标。

| 项目 | 硬指标 | 统计口径 |
| --- | --- | --- |
| 分图数量 | 100% | 每张原图独立数学子图不重复、不遗漏；不把一幅图的不连通分量另拆成图 |
| 顶点数量 | 100% | 每幅图单独一致，包含孤立点；不能用不同图的多点和漏点相抵 |
| 边数量 | 100% | 每幅图单独一致，自环一条、每条重边独立计数 |
| 端点连接 | ≥90% | 固定一致的节点对应，一对一匹配边实例，同时报告正确、漏边、多边及 precision/recall，不能靠增加预测边刷分 |
| 箭头方向 | ≥90% | 以人工判读清晰的有向边为分母，绑定正确端点；未知方向计未正确识别 |
| 顶点标签 | ≥95% | 大小写、数字、下标正确；无标签真实点保留，显示等价的下标编码可规范化 |
| 权重 | ≥90% | 数值或符号须绑定正确边，未知/漏读不能从分母排除 |
| 题干、小问 | 小问数100%；关键内容≥95% | 人工独立分条，核对条件、公式、数值和否定词；没有独立参考时标未评估，不用总体字符串相似度冒充通过 |
| 基本图形类型 | 100% | 普通无向、有向不能整体混淆；一般交叉不增点 |
| 时间 | 单张完整流程目标≤120秒 | 包含选定工具、识别、必要复核、最终校验和实际渲染；四图分别计时、独立并发 |

精度范围以原图为依据，在新版本调用前冻结。普通无向图、树与森林、有向图、加权图、常见特殊图、基础自环重边及普通平面图纳入；不能因某张图片识别失败才改为复杂图。K5、K3,3 等常见特殊图不能仅因有交叉就排除。

严重模糊、遮挡、透印、极度潦草，或大量曲线交缠、复杂重边/自环、极端稠密、复杂三维与平面嵌入，可作为诊断样本单列。无需像素级布局，也不要求非题意必要的颜色、线型、边名全对；题干确实依赖这些属性时仍需保留并核对。

所有范围都必须如实保留未确定项。图论性质、常见模板、题干预期、OCR 或路径候选的数量不能作为补删点边的答案。程序检查通过只代表数据合法，独立图像参考才用于精度计分。未知方向、未知权重和未解决的候选矛盾不能被静默改成已确认。

性能单独验收。网络或模型故障、本地选定工具未执行、最终检查未完成、未测实际渲染均须说明；快速返回 partial 或工具降级结果不算完整标准性能达标。120秒是目标，不通过强行截断、跳过必要检查或伪装成功实现。

真实响应按版本、原图摘要和首次调用保存。不同版本的最佳结果不能拼成某一版本的通过率；回放与受控模型测试用于验证实现和交互，不能当真实识别准确率。当前尚未宣称普通清晰样本全部达到上述指标。
