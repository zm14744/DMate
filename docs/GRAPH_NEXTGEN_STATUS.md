## 已实现

- 固定保留 Qwen3-VL-Plus、DeepSeek、PP-OCRv6 Small。
- NODE 独立顶点清单、跨图批量逐顶点 EDGE 读取、几何 TRACE、候选关系联合选择、按独立边 ID 的局部复核。
- 保留孤立顶点；真实中间顶点阻断跨点边；无标记交叉不创建节点；像素直线、外弧、骨架线迹复用；新增周期虚线候选。
- 每条边保留独立 ID、端点、方向、权值、边名、线迹、样式和证据。全局选择可根据新证据改选候选；数学规则不补边。
- PP-DocLayoutV3 与 Small 串行短生命周期子进程；跨进程锁、图片/请求预算、RSS 与 cgroup 准入、超时/内存压力终止。Web 进程不常驻本地模型。
- DeepSeek 使用原文锚定的短编辑，保护数字、变量和数学符号。
- 统一图形核对卡片保留平行边身份和未知方向；内部像素坐标及诊断不进入卡片。
- 新链路仅由 DMATE_GRAPH_NEXTGEN=1 启用，默认现有识别流程。异常可回退，耗时过长时受控返回错误。

第二轮在同一受限容器中单独记录模型缓存准备：128.04秒；随后4次本地模型串行请求成功4/4，15.67～25.50秒。最高单子进程 RSS 1,158,897,664 字节（约1.08 GiB），容器 memory.peak 1,136,373,760 字节（约1.06 GiB）。838次并行健康探测全部成功，最慢约25.5毫秒。RSS 与 cgroup记账口径不同，不应互相替代。
