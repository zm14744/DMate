# DMate 高校离散数学真题实测报告（2026-10-20）

## 结论

- 线上 `https://dmate.zeabur.app/chat`：以 MIT、Cornell、UC Berkeley 已公开高校试题为来源，使用中文等价表述进行 18 次实际请求，全部 HTTP 200。对返回答案的数学结论和主要推导逐条核对，本轮 18 题未发现明确的数学错误；这不能推广为整个离散数学题库的准确率。
- OCR 线上 `/ocr`：原始高校试卷图片共覆盖 Cornell 的有向关系图、原版双图同构题、DFA 转移图及 Berkeley 的数学题文字。多数请求 HTTP 200；但出现过一次 HTTP 502，表明存在本轮观察到的接口不稳定情形。
- **重大失败：Cornell CS2800 2016 春季期末试卷原卷第 10 题**。DMate 视觉识别漏边/误边，随后在识别结果上进行的数学证明也错，最终把**实际同构**的两张图错误判为**不同构**。这是真实图片输入到错误最终答案的完整链路缺陷。
- 原有 Github 图论回归与本次本地图结构检查通过，并不覆盖上述真实高校试题图形；CI 工作流的成功状态代表脚本执行成功，**不代表全部数学判定通过**。

## 重大缺陷：Cornell 原卷图同构题

**原图来源**：Cornell CS2800 2016 春季期末试卷第10题，第2页。题目包含两个具有交叉线、曲线和中心黑点的无向图。

原图正确边集（人工逐边核对并以 NetworkX 验证）：

- 左图顶点 `a,b,c,d,e`：`ab,ac,ad,ae,bc,bd,be,cd,de`，共9条边。
- 右图顶点 `v,w,x,y,z`：`vw,vx,vy,vz,wy,wz,xy,xz,yz`，共9条边。
- 两边的度数多重集都是 `{4,4,4,3,3}`。
- 同构映射：`a→v, b→z, c→w, d→y, e→x`。这个映射逐边成立。

DMate 线上首次识别却：

1. 左图漏掉 `b-e`，只给8条边，导致 `e` 的度数从3变成2。
2. 右图虚构 `w-x`，漏掉 `v-z`，误称 `w-y` 有重边，且错误看待相交处的连接。
3. 随后的 `/chat` 收到错误的图结构，输出「两个图不同构」，理由是错误的度数列。这一最终答案**错误**，不是单纯表述问题。
4. 这次原图 OCR 响应的 `graph_structures=[]`，表明像素图结构识别未提供可交叉校验的图候选。先前针对规则六点图 G3 的校验逻辑没有覆盖它。
5. 第二次同图实测，`/ocr` 返回 HTTP 502；网络/模型异常的具体起因尚未确定，不应根据一次502推断持续故障。

## 其他图片发现

- Cornell 有向关系图：`/ocr` 返回了节点文字及部分箭头，但是自环、虚线和箭头方向没有做到可验证的完整精确表达；回传包含不确定性字段，不能把成功状态当成完全正确。
- Berkeley 带数学记号的文本图片：OCR 能读出同余式等关键内容。不过本轮使用的是含参考解答的公开 PDF 页面裁剪，不适合据此评价「从题目独立解题」能力。
- Cornell DFA 状态转移图：两状态 `q1→q2` 与拆分后的三状态双 `a` 箭头有合理识别，仍需加入标记为答案的严格结构断言。

## 工程建议（按重要性）

1. **优先阻止错图导致自信错误答案**：同构、连通、树、哈密顿/欧拉、邻接矩阵等结论应基于确认的边集。不完整图结构必须允许「未知」，不能把未检测到的边默认为不存在。
2. 为原卷 Cornell Q10 建立常驻真实图像黄金样本，验证 `be`、`vz`、`vy` 等关键边及正确同构结论，必须防止跨越中心黑点时的错连与跨过无黑点的交叉线误判。
3. 新增有向关系、自环、平行边、曲线、边名/权重、空心顶点、多图、模糊/缩放/压缩等图像测试，分别统计「文字识别」「拓扑识别」「解题」的准确率，不能合并成一种通过状态。
4. 自动关键词检查只作为候选筛查，证明题仍需人工或形式化校验；例如 B07 的证明正确，关键词规则过严误标。
5. 把 HTTP 502、响应超时、限流与数学错误分别统计，至少运行多轮确认稳定性；同时加入群、格、布尔代数等当前欠测的离散数学模块。
