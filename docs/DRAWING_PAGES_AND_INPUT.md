# 独立绘图与输入界面调整

独立绘图入口位于右侧菜单“绘图”，图片上传和识别工作区保持分离。菜单上方为“错题本”和“笔记本”，留出间距后依次为“知识图谱”“绘图”“学习报告”。

## 画板

- 一个画页对应一幅图；旧版本保存的多个子图迁移为分别可访问的历史画页。
- 新建空白页、命名、自动保存、历史切换；不再提供底部保存按钮。编辑350ms后写入，切换画页、关闭和离开页面时立即保存。历史可全部删除，空历史显示“无”，名称留白；版本2空图库不会重新导入旧文档。作品保存在当前设备，账号之间使用不同存储键；存储失败明确显示。
- 左侧选择/移动、添加顶点、添加边可收起；空图库仍可点击“绘图工具”开始绘制，用户主动点击后才创建画页，关闭或重新打开工作区不会自动重建历史。删除顶点及关联边或单独删除边均点击一次完成，支持撤销。
- 撤销和重做使用固定的SVG弯箭头，不依赖操作系统字体，保留键盘可访问名称与原有历史操作。
- 画板使用固定在视口上的四角裁剪，保留桌面滚动条；滚动时不再改写大幅原图/SVG的裁剪，也不重排浮层工具栏。仅尺寸或滚动条占位变化时更新裁剪，保留图形坐标和导出内容。缩放条有独立圆角边框，两者之间留出间距。
- 移除批量编辑、子图管理、图形框选及描绘显示开关。图形结构信息打开后完整显示。
- 导出独立 PNG，仅包含绘图；保留节点、箭头、重边、权值与真实边名。手机网页提供图片预览和下载，支持安装版相册桥接。
- 顶部使用汉字“上传”，调用 `/drawing/upload` 登记 PNG 与用户实际绘制的结构，不重新调用视觉模型。导出裁剪后同步转换结构坐标，放入原有图片发送区，用户点击发送箭头才确认并解题。空白绘图和上传失败明确显示错误。
- 右侧“AI指导”通过 `/drawing/guide` 读取本画页和可选要求，提供画图指导。NetworkX 只计算现有结构事实；DeepSeek 单次回答。不会修改画图。请求按钮使用聊天发送同款圆形主题色背景、白色上箭头，SVG路径固定。画页或要求变化后旧回答失效。
- “历史绘图”位于顶部，紧邻“新建空白页”，逐行删除使用红色圆形按钮，仅显示名称，不再显示点边数量。删除前显示确认框，取消保留画页，确认后仍可将历史全部删空；等待期间若画页已编辑、切换或工作区关闭，旧确认不会删除内容。右侧的绘图设置、图形信息和 AI指导横向并排，与画布可用右边界保持留白并避开滚动条；窄屏空间不足时移到绘图工具入口下方。顶部名称和操作行与标题分隔线、下方撤销栏均留出距离。绘图工具及这些面板共用信息选择框的浮动样式，标题栏不再设红色关闭按钮；点击入口、外部或 Escape 收起，各浮动框紧贴自己的入口按钮并限制在可见视口内。绘图设置的方向只提供无向、有向，权值只提供无权、带权，不再提供“待确认”；名称使用顶部输入框。
- 绘图图形信息与上传识别共用 `DMateGraphFormat.renderGraphInformation`，使用同一格式和样式，包含类型、顶点、位置、外观及关系。信息跟随模型实时更新，新增、删除、重命名和撤销重做后不需重新打开面板，不重置画布位置。
- 新建空白页的图形标题与页面名称一致；旧历史中“绘图 N／我的图形”的默认名称差异仅同步通用标题，保留真实名称和图形结构。
- 新的无名顶点显示为1、2等普通数字，原图没有印刷名称的顶点仍保留 `label:null`；旧签名不修改。顶点属性中不再显示临时编号说明。
- 折线先绘制所有对比描边再绘制线条，作用点透明，不再切断拐点。图形与文字的不规则框可抓取任意边段局部拉伸，逐帧原位更新预览，松手后只识别一次。
- 自环可选中后拖动外侧控制点，调整大小和方向，保留为一条自环；位置使用已有 `edge.path` 布局字段保存，导出与上传沿用相同几何数据。关闭属性仅收起面板，保留所选边及控制点。
- 同色实线合并为连续路径，普通弧线和自环使用平滑曲线，保留阴影区域的自适应对比描边。添加边时显示较大的端点选择圆圈，使用固定屏幕尺寸并选择最近的顶点，实际点的显示大小保持稳定。选择圆圈不进入导出图片。

- 绘图“适应”使用实际绘制的点、线、曲线、自环、权值和标签边界缩放并居中；选择圆圈不计入边界。操作只改变相机，保留图形坐标与结构。原图片的适应行为保持原样。

## 其他交互

- 对话信息使用透明文字容器，不单独绘制底色、边框或卡片留白；删除当前对话后显示“无”，其他历史保留；刷新和云端合并不会自动打开另一段对话。
- 对话列表未选中行在白色、黑色和蓝色模式中均不绘制卡片底色、边框或阴影。黑色模式当前对话使用清晰的中灰底色，蓝色模式保留主题高亮，点击和键盘切换均更新当前行。
- 图片识别的模式标签、缩放条、框选工具条及图片视口统一使用圆角边框，条内按钮上下留白；原图像素、框选坐标和固定保存位置不变。分组标题和关闭按钮使用错题本等界面的共同字体及几何规范。
- 两类“选择信息”中的图形框、文字框删除前均显示确认框；取消不会改变选中项、识别队列或结果，确认后删除目标框并忽略它的迟到识别结果。浮层下方的信息卡边框和文字会被遮住，不再穿过浮层标题；浮层仍使用界面面板透明度设置，关闭后恢复下方内容。
- 图形框改动时取消该框的旧识别操作，立即处理新选区；超时也通知后端取消同一个操作，完成后清理控制器。AI回答绑定发起消息，消息删除后不再写回旧回答；聊天刷新保留正在输出的气泡，旧公式排版回调不覆盖新页面的滚动位置。
- 对话、消息、错题、概念和账号注销的最终删除确认按钮统一采用红色圆角矩形、白色加粗文字。历史绘图和框选来源共用 `DMateDeleteConfirm`，在已有编辑弹窗上方打开确认框，仅保留右上角红色圆形取消按钮和底部删除按钮；预布局期间隐藏整个确认框，居中稳定后显示，关闭编辑器同步取消未完成确认。
- 图片识别主弹窗固定在视口内，预布局期间强制隐藏整棵子树，避免原图自己的可见性设置提前露出一帧；等待原图加载、解码和稳定布局后再显示并聚焦关闭按钮。原图加载失败仍显示编辑器和错误提示；等待期间可按 Escape 退出，旧加载回调不会影响重新打开的编辑器。点击上传首先打开浏览器提供的系统文件选择器，它与识别编辑、分组等网页弹窗相互独立，位置由浏览器和操作系统控制，网页不指定系统窗口位置。上传触发回归验证实际输入控件、按钮和键盘入口每次仅产生一次选择器事件，空选择返回后不重开；这些用例拦截原生选择器，不能验证操作系统窗口坐标或声称修复其显示动画。`/static/file-picker-check.html` 是不加载应用脚本或样式的纯原生控件对照页，供 Windows/Edge 用户判断是否同样闪现，不读取或上传文件。图片识别结果没有内层折叠或关系省略；编辑弹窗只在内容区滚动，右上角红色关闭按钮固定在标题栏。
- 笔记本去掉静态解释、默认选择、取消选择及撤销删除；选择概念使用较大的实心圆指示。搜索框有输入时使用红色实心圆清除按钮，不显示浏览器自带的×，点击后清空搜索并保留笔记和选择状态。每个概念行右侧提供红色圆形删除按钮；删除确认弹窗只保留删除操作与右上角红色关闭按钮，不另设“取消”按钮。
- 语音不再显示底部常规提示，麦克风状态和首尾缓冲保留；空结果、录音过短或转写失败会静默恢复待输入状态，保留输入框内容，后端错误状态仍如实返回。
- 普通输入框可自动扩行，单行高度调整为桌面52px、手机48px；底部留白，发送为主题色背景、白色箭头。输入框及各类按钮不显示蓝色或红色焦点外圈，键盘操作使用控件本身的亮度反馈。
- AI停止按钮使用无图案的纯红圆形，保留停止操作及可访问名称；普通发送仍使用白色上箭头。所有关闭、删除、取消和停止的红色圆形按钮共用 `#ef4444`，悬停、按下或聚焦均不改变红色或叠加亮度滤镜；禁用时保留原有透明度和光标反馈。
- 绘图和笔记本的 AI 正文共用错题本的 Markdown 清理、数学公式保护及 MathJax 渲染路径和样式。公式渲染全局排队，旧结果与关闭的面板不会继续更新；笔记原文仍为普通文字输入。
- “取消分析”使用红色圆形按钮，取消后静默恢复；不再显示分析开始和取消后的常规说明，实际错误与 AI 正文保留。
- 笔记为空时窗口保留约320–440px的高度并限制在可见视口内，仅显示新建概念、搜索及内容区域居中的“无”，隐藏选中数量和AI操作；“AI 阅读”标题始终不显示。错题本空状态同样为“无”，聊天输入提示为“询问DMate”。

单张图片上传上限为20,000,000字节，详见 [千问上传限制](QWEN_IMAGE_UPLOAD_LIMITS.md)。

外观初始及恢复默认采用“跟随系统”，已有明确主题选择继续保留。界面面板透明度统一作用于各面板背景，保留文字、操作控件、原图片和绘图像素的不透明度；聊天气泡继续使用独立设置。对话信息、空状态、登录提示与背景预览分别使用“对话信息”“无”“未登录时不会保存信息”“无”，学习记录去掉错题数量说明，错题本统计不再使用间隔圆点。

面板透明度使用单层背景合成：普通内部卡片、结果区域和工具条继承外层面板的背景，独立浮层保留各自的一层背景；移除旧的固定局部背景模糊，继续使用全局壁纸遮罩与模糊。输入控件和选中操作仍保留底色及可辨识状态。错题本空状态仅显示居中的“无”，无单独白条。白色桌面学习报告的分隔线使用独立边框色，避免随面板透明度变淡。
