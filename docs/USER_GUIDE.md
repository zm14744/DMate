# DMate 使用指南

DMate 的主要工作区包含对话、输入区和学习工具；手机上通过侧栏打开对话列表与学习工具。AI、识图、语音、账号和云同步需要联网。本页按当前网页实现说明操作；桌面和 Android 客户端加载同一远程网页，原生权限与下载行为仍可能不同。

## 先选适合的入口

| 想做的事 | 从哪里开始 | 何时进入聊天 |
| --- | --- | --- |
| 输入一道题或讨论概念 | 主聊天输入框 | 点击发送 |
| 识别照片、截图中的文字和数学图 | 输入区“＋”，也可拖放或粘贴图片 | 核对图片后点击发送；保存本身不发送 |
| 自己画一个图，再提问 | 学习工具 → 绘图 | 绘图窗口点“上传”，回到图片工作区核对并发送 |
| 只想解释自己画的结构 | 绘图 → AI 指导 | 指导结果留在绘图窗口，不自动添加为聊天题目 |
| 整理错题、概念和学习方向 | 错题本、笔记本、学习回顾 | 这些工具各自管理记录，不要求新建聊天 |

首次使用可先完成一次最短流程：输入一道题 → 将“题目”选为“是” → 发送 → 根据提示独立尝试 → 追问需要讲解的步骤。要跨设备保留记录，先注册并登录账号；游客模式的数据保存范围见本页后文。

## 选择界面与回答语言

1. 打开“外观 / Appearance”。
2. 在“界面语言 / Language”中选择“English”或“简体中文”，立即切换，无需再点外观设置的“确认”。
3. 选择后再发送问题，新的对话、练习、复测解析、笔记分析和绘图指导会携带该语言要求。语音识别也接收当前语言提示，转写后仍由你检查并发送。

英文界面覆盖各工作区的按钮、菜单和提示，以及知识图谱名称、学习回顾的三个模块和建议。例如“错题本 / Mistake Book”“笔记本 / Notebook”“知识图谱 / Knowledge Graph”“绘图 / Drawing”“学习回顾 / Learning Review”。切换语言不刷新页面，不清空正在输入的文字、笔记或绘图，也不会重启录音；已经开始的回答继续按发送时的语言处理。

旧题干、聊天、笔记原文、绘图名称与点边标签、OCR 文字和已有 AI 回答保持原文。英文界面中仍看到这些中文内容是正常的；如需要英文讲解，可以另行提出要求。学习回顾切换显示语言时仍依据同一批记录，不修改原记录，也不额外调用 AI 翻译。

游客每次新打开或刷新网页默认简体中文，本次页面可切换为英文，但不会保存游客语言。登录后，语言按当前浏览器、当前账号保存在本地；登录或换账号时恢复该账号的本机设置，没有已保存设置时使用中文，退出后回到游客的中文默认状态。语言不跟随账号同步到其他设备，清除网站数据后也不会从云端恢复。

安装版加载新版网页即可获得网页英文界面；Android 原生离线页及权限提示的英文改动目前仅在源码中，尚未构建、发布新 APK，旧包不会因网页更新获得这些原生文案。

## 开始对话

1. 点击“新对话”，在输入框输入问题。需要记录为一道正式题目时，将输入框上方“题目”设为“是”；普通讨论设为“否”。这个选择不会被题干中的关键词覆盖。
2. 点击发送。电脑上 Enter 发送、Shift+Enter 换行；手机回车换行。输入框随内容扩展，长内容在框内滚动。
3. 解题默认先给知识点和提示。需要最终结果时明确写“完整解析”或“给出答案”；也可请求概念解释、检查自己的答案，或生成简单 / 中等 / 困难的练习。
4. 回答期间可点击红色停止按钮。继续追问时可说“当前题”“上一道题”“第 2 题”，或直接针对当前题询问；题目定位不明确时补充题干或编号。

明确的“题目：否”不新增题目档案；已有题目的正常追问仍可关联学习支持记录。AI 出题可以进入题目历史，但生成题目不代表已经作答。难度与知识分类是辅助判断，生成题目也可能需要核查。

普通文字输入最多 20,000 字符，中文、标点与表情符号都计入字符数；超过时会提示并保留输入，需缩短或拆分后发送。AI 请求的历史上限为 64 条消息、合计 120,000 字符，用户消息和 AI 回复分别计数。当前题优先完整保留，新题与已定位追问仍限定在对应题目范围。超过预算只影响本次发送给 AI 的历史，不会因此从聊天窗口删除更早消息；它也不表示 AI 会一直记住全部对话。

普通问答会边生成边接收正文，浏览器先排好收到的安全片段再显示，未闭合的公式、代码等会暂缓出现。练习出题、已确认图片和需要精确校验的题目仍先完成检查，再显示最终结果。向上滚动可暂停自动跟随；切换会话后请求仍属于原对话，只有最终成功的完整回答才保存，停止或断流不会把临时片段记为完成。兼容旧 JSON 接口时，仍可能使用最多约 8 秒的排版后显示动画。

### 题目标记与追问的区别

| 输入例子 | 建议标记 | 结果 |
| --- | --- | --- |
| “证明：有限群中元素的阶整除群的阶。” | 是 | 作为正式题目，进入题目历史并成为学习回顾可用的记录 |
| “刚才第二步为什么可以这样变形？” | 否 | 作为追问，使用已定位的题目背景，不再新增同一道题 |
| “解释等价关系和划分之间的关系。” | 否，若希望当练习题保存也可选是 | 保留正常问答；明确题目标记优先于自动猜测 |
| “给我一道中等难度的欧拉图练习。” | 通常为否 | 这句是出题请求；生成出的练习题另行登记 |

“题目：是 / 否”决定记录身份，不是限制 AI 只能解题或不能讲解的开关。图片工作区另有逐图标记，与主输入框的选择分别保存。图片分组也不是聊天中“第几题”的编号；跨多个主题提问时，应补充题干或明确会话题号。

### 常见出题问法与普通追问

不必使用固定口令，但写明动作、知识点和要求通常更容易得到合适的练习。以下按意图整理，生成题目仍使用同一套检查流程。

| 想做什么 | 问法示例 |
| --- | --- |
| 直接出题 | “给我出一道题”“请编一道集合题”“设计一道判断题”“请提供一道反证法练习题” |
| 指定知识点 | “我想练习等价关系”“用真值表考考我”“出一道关于欧拉回路的题” |
| 指定难度 | “我要简单题”“来一道入门题”“出一道有挑战性的图论题” |
| 指定题型或数量 | “设计三道集合运算题”“给我一组单选题”“请出两道填空题” |
| 换题或变式 | “换道题”“再来一道同类题”“仿照上一题改编一道变式题”“根据这道题换个数字再出一道” |
| 逐题练习 | “考考我，一次只出一道题”“出一道题，等我答完再继续” |
| 不展示答案 | “出一道简单题，先不要给答案”“出题，只给题干，不要提示和解析” |
| 同时要答案或解析 | “出一道题并给出答案”“出一道题并给出完整解析” |
| 明确的英文出题 | `Quiz me on set theory`、`Generate a practice question about graphs` |

主题、数量、题型和其他限制会随原文提交给 AI。识别这些问法，不代表生成数量、难度或答案一定准确；多题请求应核对实际输出。逐题练习需要继续发送指令，不会在后台自动无限出题。其他学科的请求仍受离散数学范围约束。

引用旧题时，会话中必须有能定位的题干。裸“下一题”优先浏览已有题目；处在最后一道时可进入继续练习。可以明确写“讲解历史第 2 题”或“再出一道同类题”来避免歧义。单说“简单点”“继续”“我不会”按当前对话处理，不能据此推断要另出一道题。

以下属于普通问答或已有题目的操作：“给出题目的答案”“请给出命题的真值表”“求出题目中的未知数”“不要再出题了，解释这道题”“出题功能为什么这么慢”。翻译、引用、代码示例里的“出一道题”也不作为实际命令；“出一道简单题，不要出难题”则保留明确的简单题请求。

生成出的可作答练习才显示题目标记，并提供记错题和图片复制操作。澄清回复，例如“你想练哪一个知识点？”，不进入题目历史。普通问答中“题目：否”的设置仍保留，AI 生成题与用户输入的手动标记分别处理。

这份汇总参考公开教学提示资料，并补充中文口语、否定、引用和追问的常见边界，见[参考资料](REFERENCES.md#教学对话与出题问法)。

### 管理对话和消息

侧栏可创建、选择和删除对话。删除对话前会显示确认窗口，确认后该对话的消息和相关学习统计一起删除；已收录到错题本的题目仍保留。消息操作中的复制用于取出文本；题目图片复制与普通文本复制是不同入口，导出效果受剪贴板能力影响。

停止回答会结束当前等待；已经发出的远程请求可能已开始执行。重新发送或继续追问前，先看聊天中已有的内容，避免重复提交自己的要求。

删除正在回答的提问或对应会话后，该回答的迟到结果不会再保存。退出或切换账号会取消当前临时问答、图片任务和未完成的回答动画，避免把旧账号内容带入新工作区；这不会删除该账号已经同步到云端的历史记录。

## 语音转文字

点击麦克风开始录音，再次点击结束并等待转写。文字插入当前光标位置，可修改后发送，不会自动提交。单段最长 60 秒；录音和转写完成前不能发送尚未收齐的输入。

麦克风需要 HTTPS、浏览器支持和设备授权。切换会话、打开编辑器、进入图片工作区或切到后台会取消录音；迟到结果不会插入其他会话。空结果或转写失败会回到待输入状态，已有文字保留。旧 Android 安装包可能没有麦克风授权代码，这时可用支持录音的浏览器，或安装包含该原生功能的客户端。

macOS 客户端需要安装包包含麦克风用途说明及录音权限，并在系统提示中允许访问。Snap 客户端还需要连接录音接口；可用 `snap connections dmate` 查看，未连接时执行 `sudo snap connect dmate:audio-record`，再重新打开应用。仓库已补齐这些原生权限配置，但已有安装包须重新构建、分发并安装后才会获得配置变更，网页更新不会替换原生权限。

转写只是输入辅助：检查集合符号、变量名、上下标、数字和否定词后再发送。授予麦克风权限不代表已经发送聊天消息；录音期间的文字仍由你决定是否提交。

## 上传、核对与分组

1. 使用上传“＋”、拖放或粘贴添加图片，每批最多 4 张。单张最多 **20,000,000 字节**，解码像素最多 **7680 × 4320** 的总量。
2. 每张图片独立识别。识别完成后点击“编辑”打开核对窗口，左侧看原图，右侧看“文字信息”和“图形信息”。核对全部小问、公式、顶点、端点、箭头、重边、自环和权值；状态提示不等于数学正确性保证。
3. “原生识别”保留首次扫描的独立结果。需要重新选择局部时切换“自主框选”，选择文字或图形框选工具，框住所需内容。矩形和不规则框都可调整；不规则框可拖动局部边界，松手后重新识别该区域。
4. 自主框选中的“选择信息”分别管理文字框和图形框。新框识别后需要勾选才放入当前组合，可多选、拖动排序、删除。自主模式只组合所选框，不自动补入原生结果；随时可切回“原生识别”。选中的来源尚未完成、失败或为空时，先处理该来源再保存。
5. 点击“保存”校验并关闭核对窗口，不发送消息。核对后的图片卡片只显示“已核对”和“编辑”按钮；文字、图形和可选要求在“编辑”窗口查看或调整。未填写要求时不会自动附加“我的要求”。
6. 回到图片工作区，打开右上角“分组”。逐张选择是否为题目及组别；默认每张各一组。同一道题跨两张照片时放在同组，独立题保持分组。
7. 点击发送后立即回到聊天输入框，等待期间可点红色停止按钮。系统先核验所有图片及各组内容，再依组回答；未完成的图片在处理期间保留，停止或失败后重新显示。同组按上传顺序提交并共用一份回答；组内任一图片标记为题目，该组就按一道题记录，全组为“否”时不计入题目统计。图片组号与会话题号分别编号。

直接发送未保存的有效结果也会先执行同样的确认。识别未完成或确认失败时整批不会开始解题；停止、失败或切换会话会保留未完成图片，重试不会重发已完成的组。图片与识别草稿属于当前页面工作状态，不应依赖刷新恢复。

图形信息会展示图类型、顶点、位置、外观和边关系。无名顶点使用临时数字编号，编号只在当前子图内有效，不是原图的印刷标签；多图提问应写清“图片 2 的图 1 从 1 到 2”。边名和权值是不同内容，不应把同一个数字重复当作两者。外观与坐标仅供定位，不能用交叉画法推断连通或同构关系。

### 两种核对模式如何选择

**原生识别**展示首次自动扫描的快照，适合完整题面已经识别清楚的情况。切换到自主框选不会改写这份原生快照；切回原生模式后仍可查看它。当前扫描窗口的“文字信息”和“图形信息”是结果展示区，不是任意改写文字或粘贴 JSON 的输入框。

**自主框选**用于缩小识别范围、排除旁边另一道题、调整题干与图形组合。推荐按以下顺序操作：

1. 切到“自主框选”，先用选择 / 平移和缩放找到目标区域。
2. 选择“文字框选”或“图形框选”，再选择矩形或不规则框；只圈住需要的内容，避免把另一道题带入。
3. 等待该框识别完成。拖动边界后会重新识别，旧结果不会继续当作新范围的结果使用。
4. 在对应区块的“选择信息”中勾选需要的框。**新建框默认未选中**，识别完成也不会自动放入最终组合。
5. 多个文字框按来源列表顺序拼接，多个图形框按来源列表顺序组合。需要换顺序时可拖动来源卡片；设备不支持拖放时不要依赖该操作完成排序。
6. 删除来源先经过确认；只是不想本次提交某一框时，取消勾选即可，不必删除。
7. 检查右侧最终汇总，再点“保存”。有文字或图形即可保存；所选框正在识别、失败或为空时，保存按钮会禁用。

自主组合只包含当前所选框，**不会自动带入原生模式中的题干或其他图**。例如只选图形框后，原生题干不会跟着发送；一道“文字条件 + 图”的题应同时选择相应文字框和图形框。图形框也可能识别出多幅独立子图，最终仍要逐图检查。

如果仍有识别错误，可重新调整框选范围或换用更清晰的原图；文字问题也可转为主聊天框中的手动输入，已有明确结构可用独立绘图重建。可选要求用于说明你真正想问什么，不能替代对错误连边和权值的核对。

### 分组示例

| 上传内容 | 分组设置 | 本次发送 |
| --- | --- | --- |
| 第 1 张是题干，第 2 张是同题配图 | 两张同组，题目标记至少一张为“是” | 一条题目消息、一份回答，正式题目记录按一道题处理 |
| 两张分别是互不相关的题 | 分成两组，各按需要设为题目 | 按组分别发送和回答 |
| 一张概念示意图，只想讨论画法 | 单独一组，题目标记为“否” | 正常问答，不新增正式题目档案 |

每张图片的“要求（可选）”仅跟随该图片；主输入框中的补充文字在这次批量发送时作为各组的共用要求。不要把只针对其中一道题的要求写成所有组的共用指令。没有填写就保持为空，系统不会代写“我的要求”。

### 保存与发送状态

| 状态或动作 | 含义 | 接下来怎么做 |
| --- | --- | --- |
| 识别中 | 仍在读取这张原图 | 等待，或用该图右侧红色圆按钮取消 |
| 待核对 | 已有草稿，尚未确认 | 打开“编辑”对照原图 |
| 修改未保存 | 当前组合与已确认快照不同 | 重新保存；发送也会先执行确认 |
| 已核对 | 当前内容已通过确认 | 外层只显示状态和“编辑”；可继续编辑或发送 |
| 识别失败 | 该图没有可直接发送的结果 | 编辑选区重试、改用清晰图片，或移除 |
| 正在保存 / 正在解题 | 正在提交对应操作 | 等待；解题期间可停止 |

图片卡片在识别中、待核对和已核对时都不显示文件名标题，以缩略图区分图片；电脑上悬停缩略图仍可查看文件名。核对后外层卡片不再重复展示全文、结构预览、保存说明或要求框；这些内容仍保存在任务中，并可从“编辑”查看。保存不是题目发送，也不是把图片草稿永久存入云端。

一批图片先完成全部确认与组内容检查，才开始请求第一组答案。已经成功回答的组会从图片工作区移除；失败或停止后的未完成组仍可继续处理。相同内容重试会复用该组已提交的用户消息，避免重复追加；若改了题干、结构、分组或要求，则属于新的提交内容。

## 独立绘图

学习工具中的“绘图”打开独立画板。可新建或重命名页面，在“历史绘图”间切换；每个浏览器所属工作区最多保留 50 张。

绘图工具支持顶点、边、方向、权值、边名、曲线与自环，可选择对象修改属性、撤销 / 重做并调整布局。“适应”将实际图形居中；缩放不改变数学结构。“绘图设置”选择无向 / 有向、无权 / 带权，“图形信息”随编辑更新。

- **导出**：保存当前画板为 PNG；手机可显示图片预览，支持的 Android 客户端可存到相册。
- **AI 指导**：按当前画板和可选要求解释结构，不自动改图，也不把它登记为一道解题请求。
- **上传**：把当前绘制结构加入图片工作区，核对并发送后才进入对话。系统使用你绘制的结构，不重新猜测导出图片中的边。

**游客绘图只保存在当前页面内存**：关闭绘图弹窗后，在同一页面重新打开可继续使用多张画板；刷新或关闭网页后清空，不从 localStorage 或 sessionStorage 恢复。旧版保存在本机的游客图库会清理，不导入新的临时工作区。

登录后的绘图自动保存到当前浏览器按账号区分的本地图库，刷新后可继续使用，**不参与云同步**。清除网站存储会丢失该设备的账号图库，换设备登录也不能恢复它；重要内容请导出。

出现本机存储不足提示时，新内容仍暂存在当前页面；同页关闭并重开绘图弹窗不会退回旧画板，学习回顾也会读取当前草稿。恢复写入成功后才算保存到本机，刷新、关闭网页或切换账号前请先导出。

历史绘图没有记录时，“无”居中显示。绘图中的操作失败或存储问题会在画板上方弹出提示，点击右上角红色圆形按钮关闭；提示没有底部确认按钮，关闭提示不会关闭画板。连续存储失败只提示一次，成功保存后再次发生故障才重新提示。

### 一次完整的画图操作

1. 点“新建空白页”，在名称输入框命名，例如“欧拉回路练习”。
2. 打开“绘图设置”，选择无向或有向、无权或带权。菜单只提供明确类型，不提供“待确认”选项。
3. 从“绘图工具”添加顶点和边；选择对象后在属性面板改端点、标签、方向、权值等。带箭头的边还可反转方向；边名和权值分开填写。
4. 用选择 / 平移工具检查画布；必要时点撤销、重做或“适应”。选择某条边只打开属性面板，不等于立即选择了端点菜单里的某一项。
5. 在“图形信息”核对当前点、边、位置和外观描述。位置依据实际布局更新；拖动顶点不会把画面位置变成新的数学条件。
6. 仅需图片时用“导出图片”；需要提问时用“上传”。上传后仍应核对，再点击发送。

“历史绘图”按最近更新显示本机页面，可切换、删除；删除前有确认。新建页面不会自动清空旧页面，“清空”针对当前画板，操作前请确认当前页名称。若浏览器提示存储不足，画面仍可能留在当前页面，但不能据此认为保存已成功，应先导出再关闭。

手机上的工具和属性面板可能需要内部滚动；先关闭不需要的面板再操作画布。端点、方向等选择采用页面内选择弹窗，红色圆按钮用于关闭当前弹窗，不是确认选择。

## 错题、笔记与学习回顾

**错题本**：从题目消息收录错题，保存解析和笔记，完成订正后发起同类复测；提交复测答案后记录通过、未通过或待进一步判断。支持搜索、筛选、排序、单题复制和 PDF 导出。当前错题容量为 240 条；复测尽量沿用原知识点与已存难度，生成题仍需核查。

**笔记本**：新建概念，填写名称与原文，输入时自动保存。打开或编辑概念不代表选中；勾选后可点“AI 解释”，选择至少两条可“分析关联”，并添加补充要求。AI 只读取本次所选笔记和补充要求，不读取其他笔记、旧聊天或错题，也不覆盖原文。修改、删除、换选或关闭会取消 / 忽略旧分析。

笔记常规容量为 100 条、合计 180,000 字符；每条名称最多 160、正文最多 6,000 字符。单次 AI 分析最多 12 条、名称与正文合计 24,000 字符。保存失败时保留当前页面并处理提示，关闭页面前不要假定已经云同步。

**学习回顾**：使用本地规则，综合聊天学习记录、错题、独立绘图和概念笔记，整理为“最近学习”“值得再看看”“接下来可以做”三段概要文本。完全没有内容时只显示“无”。打开时不额外请求模型，不展示数字面板、档案、筛选或快捷按钮。

**知识图谱**：目前含命题逻辑、谓词逻辑、证明与归纳、集合与关系、函数、初等数论、计数与组合、递推关系、图论、代数结构，共 68 个节点。可按当前题、会话或历史聚焦，查看相关节点及建议前置关系；这些关系用于学习安排，不等于严格逻辑蕴含。支持缩放、拖动和复制图谱 PNG，浏览器不允许写图片剪贴板时尝试下载。

### 错题的推荐整理顺序

1. 在题目对应消息中点“记为错题”。若一段内容含多道题，先选真正需要记录的题，不要把整段讲解当作题干。
2. 在上方“题目预览”查看完整的只读排版，在下方“编辑题目”修改原文、补全条件；上方的文字、公式和 Markdown 会实时更新。点击“确认”保存编辑后的题干，再查看或补充参考答案、分步解析、错误原因和自己的笔记。多题逐道确认，关闭窗口仅取消尚未确认的题目。
3. 独立重做后记录订正。“已订正”表示完成整理，还不等于复测已通过。
4. 发起同类复测，先作答再提交诊断。复测尽量沿用原知识点和已知难度，但题目及判定仍须检查。
5. 在错题本查看复测记录；未通过时回看思路再订正，待进一步判断时不要直接当作通过。

错题本的“待处理 / 已订正”、搜索和排序共同决定当前列表；PDF 导出以当前筛选结果为范围，不默认导出所有隐藏项目。列表允许保留不同学习经历中的重复题，PDF 按题干去重。编辑题干会清除旧题对应的自动分类、参考答案和解析，已有订正、复测历史及笔记仍需自行判断是否适用。

重复题可以逐条修改笔记或题干，保存只作用于正在编辑的那条。跨设备冲突合并时，较新记录主动清空的内容会保持为空，不会恢复旧笔记或把旧题答案填入新题。

“错误次数最多”把相同题目收录条数最多的排在最前面：例如同一道题保留 3 条记录，排在只保留 2 条或 1 条的题目前面；条数相同时按最近更新排列。手动和自动收录的每条记录都计一次，答错次数与复测失败次数不影响这个排序。按完整题干归一空白后比较，保留大小写差异，重复条目仍分别显示。搜索、状态筛选不会缩小计数范围；删除记录或修改题干后会重新计算。顶部统计保留总数、待处理和已订正数量。

导出范围内没有错题、PDF 组件加载失败或生成异常时，会出现应用内“无法导出 PDF”弹窗。只需点击右上角红色圆形按钮关闭；弹窗没有底部确认按钮。筛选结果为空时，可先调整筛选再导出。

### 概念笔记的选择与 AI 分析

笔记名称和正文输入时自动写回当前工作区。列表中打开某条笔记只是编辑它；要让 AI 读取，应勾选该条。先写下自己的定义、例子或困惑，再选择“AI 解释”；比较两个以上概念时选“分析关联”。结果在分析区显示，不会替你改写笔记原文。

例如可分别记录“等价关系”“划分”，勾选二者后补充“用同一个集合举例，说明二者如何互相确定”。没有勾选的其他概念不进入这次分析。切换账号、关闭窗口、修改或删除所选内容后，旧请求结果不会再覆盖新选择。

### 学习回顾的三个模块

有相关内容时，“学习回顾”按三个同样样式、纵向排列的概要模块展示：

| 模块 | 应如何阅读 |
| --- | --- |
| 最近学习 | 回想现有记录涉及的知识主题与学习内容 |
| 值得再看看 | 留意尚需订正、复测或进一步梳理的内容 |
| 接下来可以做 | 从概要建议中选择下一项学习行动，再自行打开错题本、笔记本或对话操作 |

没有任何内容时，正文只显示“无”；已有内容但某模块没有依据时，该模块显示“无”，不放引导文案。绘图和笔记会与聊天、错题一起参与摘要，即使没有聊天记录也能单独形成回顾；未添加内容的空白画板和空笔记不算学习记录。游客只使用当前页面的绘图，登录账号只读取自己的本机图库，不读取其他账号的画板。

回顾不提供题目筛选、活动时间线、数字面板或跳转按钮，也不通过模型生成评价，不编造学习时长、正确率、能力分数、掌握度或未发生的活动。

普通概念交流也能参与，例如没有标成题目的“量词否定怎么理解”；只有问候、功能操作或仅 AI 回复中出现的主题不会单独形成学习记录。主题使用本地规则识别，隐含主题和只有代词的追问可能被遗漏。只有标题的笔记会提示补充定义或例子，空白画板不参与；绘图会读取实际文字与图结构，不因画过图就认为掌握图论。

建议优先处理有明确复测失败、待订正或待复测的题，再参考其余记录。手动通过标记与自动判断会分别考虑；旧通过不能掩盖新失败，新一轮尚未完成也不会套用旧结果。回顾不改变任何通过标记或原有计数。

按建议操作时，先完成一个小任务，再检查自己的理由，而不是只重新阅读答案：

| 记录涉及的主题 | 可执行的复习方式 |
| --- | --- |
| 量词与逻辑 | 写清论域，把量词式译成一句话；写否定后检查量词与条件是否正确变化 |
| 关系性质 | 从定义出发判断；若不成立，给出违反条件的具体元素或有序对 |
| 证明与归纳 | 分清已知、待证、基例与归纳步骤，找出使用假设的位置，避免把结论当成前提 |
| 计数、递推 | 先判断是否考虑顺序与重复，枚举小规模情况；递推先手算前几项，再代回核验 |
| 概念笔记 | 遮住正文复述定义，给一个例子，再对照原文补遗漏的条件 |
| 绘图 | 按固定顶点顺序把边转换成邻接矩阵的一行，核对方向，并说明重边、自环或权值采用的约定 |

错题做完后，可把改正的一步写到“我的笔记”，核对后再标记订正；已经订正的题再独立复测。若无法起步，可以先看同类例题的一步，再合上重做。已有通过记录的题可在下一次学习时做个小变式，回顾不会因此宣称已掌握或编造复习截止日期。相关依据见[学习建议参考资料](REFERENCES.md#学习回顾与学习建议)。

有真实时间的记录按记录时间排序；旧聊天缺少消息时间，不会被写成某一天发生的学习。“最近学习”摘录各来源的代表内容，不是完整清单。删除对话或单条消息后，缺少当前来源依据的旧事件不再单独提供主题；保留下来的错题仍可独立参与摘要。正式题目标记、同组多图按一道题记录、知识图谱的题目定位都继续有效，只是不再在回顾窗口铺开成题目档案或计数。

### 使用知识图谱

打开后先选择聚焦范围或模块，点击节点查看知识说明及相关题目。手机初次显示会按可用窗口适应图谱；仍可用“＋ / －”放大缩小，用“适应”重新容纳当前图形。完整查看模式扩大查看范围，不会把知识关系改成新的题目。

图谱的节点和建议前置关系来自内置知识结构，当前题或历史记录决定哪些内容与本次学习相关。它不是用颜色评价你“已经掌握 / 没有掌握”的测评系统；普通图谱索引采用本地分类接口，不因为打开窗口就发起模型调用。

## 账号与数据保存

未登录时，聊天、学习记录、错题、概念笔记、外观和独立绘图都只属于当前页面，刷新或关闭网页后不保证保留。游客绘图可在同一页面关闭并重开绘图弹窗后继续，但不会持久保存。

注册使用用户名、邮箱、密码和邮箱验证码；登录支持用户名或邮箱。注册成功返回一次恢复码，请妥善保存。账号面板还提供绑定 / 更换邮箱、邮箱或恢复码找回密码、修改恢复码、退出及输入当前密码永久注销。

登录后，会话、学习记录、错题和笔记保存在本机缓存并同步到账号；外观参数按当前浏览器、当前账号保存在本地，不随新快照跨设备同步。多设备冲突自动合并并按修订号重试，必要时保留会话或笔记副本。退出前查看同步状态；未同步内容在退出清理学习缓存后可能无法找回。自定义背景图片和独立绘图库也只在本设备保存，不能通过登录恢复到另一台设备。

| 数据 | 游客刷新后 | 登录后跨设备 |
| --- | --- | --- |
| 聊天、学习记录、错题、概念笔记 | 不保证保留，仅用于当前页面 | 本机缓存并云同步，以同步成功为准 |
| 外观参数 | 仅用于当前页面 | 按账号保存在本机，各设备分别设置，不参与云同步 |
| 界面语言 | 仅本次页面，新打开或刷新后默认简体中文 | 当前浏览器按账号保存，不参与云同步；换账号读取该账号在本机的设置 |
| 自定义背景图片文件 | 当前页面 Blob，不持久保存 | 本设备 IndexedDB，不同步图片本体 |
| 独立绘图历史 | 当前页面内存；重开绘图弹窗可继续，刷新或关闭网页后清空 | 账号分区的本机图库，刷新可保留，不云同步 |
| 尚未发送的原图与识别草稿 | 当前页面任务，刷新不能依赖恢复 | 不作为账号的图片任务列表同步 |

注销账号会删除账号和云端同步数据，并返回空白游客工作区；这是永久删除操作，需要当前密码。退出登录只是结束登录状态，不能用它代替注销。有关第三方服务接收的数据与服务端保存边界，见[数据与隐私](SECURITY_PRIVACY.md)。

## 外观、复制与设备差异

“外观”支持跟随系统、白色、黑色和蓝色，初始与恢复默认均为跟随系统；可调强调色、字号、壁纸、背景适配、遮罩、模糊、面板及聊天气泡透明度。登录后参数按账号保存在当前浏览器，各设备分别设置；外观参数和壁纸图片本体均不上传到云同步。

蓝色、绿色、紫色强调色也用于用户消息气泡，黑色主题不会单独改成灰色。“跟随系统”读取设备的明暗偏好，自动切换白色或黑色；系统变化、页面重新显示或回到前台时会重新应用。手动选择白色、黑色或蓝色后，不再被系统变化覆盖；重新选择“跟随系统”才能恢复自动切换。

Android 源码版本 1.0.3 和 Windows / macOS 桌面源码版本 1.0.2 包含宿主直接报告系统明暗的支持，用于 WebView 媒体查询没有及时更新的情况。主题切换在当前页面进行，不为切换主题重载聊天；普通浏览器、iPhone / iPad Web Clip 和 Linux 桌面客户端继续读取浏览器的系统偏好。源码版本不表示下载入口已经发布新包，旧安装版必须更新到包含修复的包，不能仅通过刷新网页获得原生修复。实际切换效果仍需在对应设备上检查。

如果没有跟随变化，先检查外观面板中是否选中了“跟随系统”，再确认系统的应用明暗设置，切换后回到 DMate 前台，并核对实际安装版本。另一台设备上的主题选择不会同步覆盖本机设置。Linux 的报告还取决于桌面环境和 WebKitGTK；不需要清除聊天或学习数据来排查外观问题。

公式使用 LaTeX 渲染。题目、错题和所选文字可复制；支持富文本的浏览器尝试保留格式与公式图像，否则回退为文本 / LaTeX。剪贴板、PDF、文件选择、相册和麦克风能力依赖设备及浏览器。客户端打开远程网页，网页更新不能替换已安装程序里的 Android / Tauri 原生代码。

网页的 DMate 标志使用矢量图，高像素密度屏幕和页面缩放会按实际分辨率绘制。v52 品牌、浏览器专用标签及普通应用图标按黑底白线多面体参考图重绘为矢量路径，继续使用统一的 4.5 / 256 线宽，各尺寸按同一比例缩放；搜索结果专用图标另做小尺寸线条增强。它保留参考图的轮廓和线框风格，不是将旧小图放大，也不承诺与截图逐像素相同。网页更新后，已有标签页需要重新加载才能使用新图；游客应先保存需要保留的内容。手机 / 电脑桌面的安装图标属于安装包，需要安装包含新图标的新版本；iPhone / iPad Web Clip 需要更新描述文件。旧快捷方式可能保留系统缓存，可在更新后重新创建，不需要删除学习记录。各平台资源与更新方式见 [README](../README.md#高清图标与更新方式)。

普通电脑屏幕上的左上角标志会按像素密度进一步提亮细线，改善发灰、发虚的观感；图标大小和线宽保持一致。补偿会跟随浏览器缩放和显示器像素密度调整，手机及高清屏直接使用新版矢量图，不叠加这项补偿。这项优化属于网页更新，已安装的桌面客户端重新加载网页后也能使用。

供 Bing 等搜索结果抓取的图标采用独立的 v53 版本：网站为已识别的手机和电脑搜索爬虫提供相同的不透明黑底白线多面体，适当加粗搜索图标的线条，使小尺寸更清楚。网页品牌、浏览器专用标签和安装版图标保留 v52 原线宽；仅这项搜索显示优化不需要重新下载安装包。搜索引擎仍会自行处理和缓存图标，可能显示旧图或通用网站图标，不能保证部署后立即修正手机或电脑的搜索结果，也不能仅凭截图确定异常原因。普通用户不需要清空学习数据；站点所有者可通过站长工具请求重新抓取，具体生效时间由搜索引擎决定。

## 安装版下载与更新

下载安装弹窗优先提供 GitCode，GitHub 为对应平台文件的备用来源，点击后直接下载对应附件；相应平台的 Microsoft Store、Snap Store、itch.io 等商店入口继续保留。Android 当前文件名为 `DMate-Android-1.0.3.apk`；桌面入口仍为现用的 1.0.0 文件，iPhone / iPad 使用全屏描述文件。下载源统一不表示所有平台的安装包版本都相同或都已包含最新源码修改。

各平台的下载安装弹窗统一提示“选择下载源”；非 Linux 平台的 GitCode / GitHub 按钮只显示源名，Linux 保留 DEB / AppImage 格式后缀，并增加 itch.io 入口。

下载等普通弹窗在手机可用区域内居中显示；内容超出可用高度时，可以在弹窗内上下滚动查看所有下载选项和操作按钮。系统自带的文件选择或安装窗口仍由浏览器及操作系统控制。

Android / 桌面安装版只在实际发布的原生安装包版本高于当前版本时提示更新，例如原生功能、客户端内嵌图标或原生配置更新。网页翻译、语言功能、页面样式、交互和 Python 后端等随网站部署更新，不弹安装提醒。当前发布清单仍为 Android 1.0.3、桌面 1.0.0；接入这项提醒无需重新下载安装包，iOS Web Clip 不参与原生版本比较。

更新提醒居中显示，右上角的实心红色圆点可关闭，同一会话不重复提示相同版本。下载渠道仅为 GitCode / GitHub；Linux 可选 AppImage 或 DEB，每种格式都提供这两个来源，下载后由你手动安装。旧 Android 会通过外部浏览器下载；旧桌面客户端若无法打开新窗口，可点击后复制地址到浏览器。网站不保留旧 APK 下载入口，请使用公开附件。

安装版在启动、每 6 小时、回到前台及恢复网络时检查更新，频繁切换前台会节流，离线不会打扰。生成回答、OCR、同步、输入或其他弹窗进行时，以及程序在后台时，提醒会延后显示；不会暂停同步、刷新页面或修改学习记录。源码版本增加、构建成功不代表新安装包已经发布。系统暂时显示旧快捷方式图标时，可在安装更新后重新创建快捷方式，不需要删除学习记录。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 图片显示“已核对”，但还没有 AI 回答 | “保存”只确认内容；回到图片工作区后还要点击发送 |
| 自主框选识别出了内容，右侧汇总却没有 | 打开对应的“选择信息”，勾选该来源；新框不会自动选中 |
| 只剩图形，没有原生题干 | 自主模式不混入原生快照，需要另框并选择文字区域 |
| 保存按钮不能点 | 当前组合不能全空；所选框不能仍在识别、失败或为空 |
| 发送后图片工作区消失 | 正常：等待回答时回到聊天输入框，红色按钮可停止；未完成图片在停止或失败后恢复 |
| 学习回顾没有提到某道问题 | 回顾是概要，不逐题列档案；检查正式题目标记与原记录是否仍存在，普通追问不新增题目 |
| 登录另一台设备看不到绘图或壁纸 | 账号图库与壁纸图片本体只保存在原设备，不属于云同步数据 |
| 游客重开绘图弹窗有画板，刷新后却没有 | 重开弹窗仍在同一页面内存中，刷新或关闭网页才清空；离开页面前先导出重要绘图 |
| 系统选文件窗口位置或动画异常 | 这是操作系统和浏览器的原生窗口；网页可以触发选择，不能决定其系统窗口出现位置 |
| 麦克风无法启用 | 检查 HTTPS、网站权限、系统麦克风权限、设备是否占用，以及客户端是否包含相应原生授权 |
| 复制图谱或题目图片失败 | 先尝试下载或图片预览；某些浏览器不支持直接写入图片剪贴板 |
| 刷新后游客聊天没有了 | 游客聊天没有持久保存保证；需要长期保留时登录并确认同步成功 |

定位问题时记录发生在哪个工作区、进行了什么操作以及页面提示；识别问题尽量指出具体图片、子图、端点或缺失文字。不要把密码、恢复码、验证码或模型密钥发进聊天。
