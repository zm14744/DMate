# 图片核对与独立绘图

当前来源管理和输入行为见[原生扫描、框选来源与多行输入](SCAN_SOURCES_AND_COMPOSER.md)。

外层上传界面恢复原来的紧凑卡片、缩略图、上传按钮和四图独立状态。布局调整只应用于点击「编辑核对」后打开的界面。

- 左侧保留完整原图、缩放、适应，以及图形框选和文字框选。支持矩形与一笔不规则圈选；松手提交，可连续框选，框选后保持当前位置。
- 右侧只读显示文字、顶点、边、连接关系、方向与权值；没有系统重绘的 SVG 图形，也没有节点、边或正文编辑表单。
- 下方仅有可选要求和保存操作。放入当前组合的信息改变时，旧确认失效；解题仍依据最新确认的结构。
- 右侧菜单中的独立「画图」入口保留，保存到当前浏览器，与识别任务分开。

独立绘图的边方向只提供「无向」「有向」，端点列表直接显示现有节点。图形信息根据当前画布坐标生成相对位置和外观描述，移动顶点后同步更新；AI 指导使用同一份最新位置和描述。已有识别图片中的原始外观描述仍然保留。

手机端的单选下拉框复用知识图谱模块选择弹窗，使用浏览器顶层对话框覆盖绘图和图片编辑窗口；取消不修改原选择，也不关闭下层面板。桌面端继续使用原生下拉列表。

图形框选调用 `/graph/recognize-region`：先验证浏览器任务与原图绑定，再把多边形以外像素涂白，裁出选区，调用现有千问图识别和必要检查，最后将坐标映射回原图。一次选区可能返回多幅数学图，不根据框数伪造图数。图形框只更新图形信息，不混入题干。

文字框选调用原有批量 `/graph/text-region`，使用用户指定顺序，旧调用默认按框编号。初次AI扫描独立保留；自主框选模式按用户选择组合文字与图形来源。缩放、平移、拖框边界不会反复触发识别，只在范围提交后识别。删除、重新框选或关闭后，旧结果不得重新写入。

选区线宽为固定屏幕 1px，保留较宽的透明拖动区域。扫描模式下，框选手势优先于旧边框的拖动命中；选择/平移模式才调整旧框。这避免了从旧框边附近开始一笔圈选时被误当成缩放旧框的问题。独立绘图的原有交互不受影响。

测试覆盖外层界面恢复、桌面/手机布局、只读信息、无系统绘图、两种类型的矩形/不规则框、连续圈选、视图稳定、编号顺序、删除后忽略迟到结果、确认快照，以及服务端选区遮罩、坐标回映和原图身份检查。
