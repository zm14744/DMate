# 原生扫描、框选来源与多行输入

2026-10-29

## 权值与边名

视觉主识别及局部复核明确区分两个字段：`weight`是权值，`edge_label`仅用于独立标注的边名，没有名字使用null。一个数字不能同时被当作两种标注。规范化会移除无独立标注依据的同值数字重复，保留权值、端点、方向和边实例；独立数字边名由 `edge_label_is_explicit:true` 保留，该字段通过确认签名和解题快照传递。用户在独立画板输入边名也视为明确命名。

旧草稿的显示兼容只去掉重复的数字边名，不修改已签名的数据。标题已完整表达正确图类型时，不再重复渲染下方类型行。实际测试 `oct24_001`：40.015秒，7点9边，9个权值保留、边名均为null，返回complete；该单张测试不代表所有图片完全正确。

## 两种模式

- **原生识别**显示初次AI扫描的独立副本，不显示“选择信息”或框选管理。框选、删框、后台迟到结果和保存当前组合都不能覆盖它，可随时切回。
- **自主框选**只使用用户勾选的框选结果，不合并原生文字或图形。新增框立即识别但默认不选中，勾选立即组合，支持同时选中多个框。
- 文字、图形信息各自位于独立边框卡片中。自主模式右上角各有“选择信息”，打开不会挤动画布的浮动弹窗。每行仅有“文字框1／图形框1”的圆形选择项及并排红色圆形删除按钮；没有放入、重试、上下移动、状态或预览控件。拖动行仍可排序，关闭与 Escape 保留当前选择。
- 框编号不随排序改变。图形队列按当前顺序处理尚未开始的请求；文字批量请求通过显式 `order` 字段传给同一个OCR worker。已完成结果调整顺序时直接重新组合，不重复请求模型。
- 未选中的失败框不阻止保存原生结果或其他有效来源；被选中但未完成/失败的结果不能伪装成完成。删除框同时清除其范围，旧响应忽略。
- 保存仍只校验并退出。重新打开查看时，不会仅因规范化元数据不同而使已确认结构失效。发送仍依据最后保存或发送时确认的组合。

## 语音首尾保护

麦克风节点接好且收到第一个真实音频块后才显示开始录音。结束时继续接收约350ms尾音，使用更小的采集块，并刷新重采样器末样本；提交WAV包含150ms前置静音和250ms尾静音，总长度仍不超过60秒。录音或识别尚未结束时不能提前发送不完整输入。

模型和词库保持不变，不增加调用次数，不拼凑遗漏文字。麦克风真正启动前的声音无法恢复；这些修复减少客户端截断，不能保证模型永不误识别首末字。

## 常规文字输入

普通聊天区使用圆角多行输入框，左侧上传“+”，右侧麦克风和发送箭头。输入、粘贴和语音插入会自动扩行；超过约六行或小屏可用高度后内部滚动，发送清空后恢复。桌面Enter发送、Shift+Enter换行；手机回车换行，中文输入法确认候选不发送。
