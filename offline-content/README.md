# DMate 离线学习内容包

本目录保存离散数学概念与练习的简体中文原文和完整英文译文；实际数量和各章覆盖见自动生成的 [覆盖清单](PREVIEW.zh-CN.md)。

## 文件

- `concepts.zh-CN.json`：课程大类概述与独立的细分概念，含定义、说明、符号、例子、易错点与关联练习。
- `questions.zh-CN.json`：分层练习、答案、解析、评分要点及精确的概念关联。
- `references.zh-CN.json`：本次联网核验的原项目、固定修订、参考章节和商业许可证据。
- `SOURCES_AND_LICENSES.md`：原创内容与第三方作品的界限、商业分发和未来改编规则。
- `PREVIEW.zh-CN.md`：从实际 JSON 生成的逐大类覆盖表。
- `i18n/en/part-0.json` 至 `part-3.json`：按原始编号保存标题、正文、选项、答案、解析和评分要点的英文译文。
- `i18n/en/source-manifest.json`：中文显示字段的校验摘要；原文变化后必须重新核对相应译文。
- `example-practice-migration.json`：逐概念审核的例题迁移清单，记录独立中英文题干、难度理由、原例摘要和原561道题的兼容基线。
- `question-concept-classification.json`：逐题细分概念归类记录，保留原关联、归类理由和变更前后摘要；重建原关联后核对原记录，保证题干、答案与其他元数据未随归类改变。
- `static/offline-content/translations.en.json`：同步脚本合并生成的离线发布副本，不能手工编辑。

## 内容层级和兼容

根目录 `knowledge_graph.json` 定义课程大类；每个大类下还需要多个具体概念。大类概述保留原节点编号，细分概念使用独立编号，并通过 `graph_node_id` 归属到图谱节点。概念前置关系使用概念编号；题目的 `knowledge_points` 指向实际考查的概念，`graph_node_ids` 由这些概念自动推导。

大类概述可以浏览细分概念和该大类全部练习，细分概念可以返回所属大类并打开关联题目，题目也可以返回所考查的概念。原有 `q01`–`q14` 编号继续保留，以兼容已保存的本地练习记录。离线错题本和笔记本保存当前账号的本机副本，游客资料只在当前标签页保留；升级不会清除已有浏览器中的历史数据。

## 编辑、同步和检查

以本目录的两份内容 JSON 为编辑源，不直接编辑 `static/offline-content` 副本。修改大类结构、概念或题目后运行：

```sh
python scripts/sync_offline_content.py
python scripts/sync_offline_content.py --check
python scripts/test_offline_content.py
python scripts/test_offline_content_math.py
python scripts/test_offline_translations.py
```

脚本验证大类覆盖、每类至少三个细分概念和八道分层练习、前置关系无环、题型与答案字段、精确概念关联及参考章节；同时生成双向导航、覆盖清单与静态发布副本。内容减少或关联失效时检查会失败。调整原始内容时仍须自行复核数学正确性，结构检查不能证明自然语言题目及证明全部正确。

数学回归另外固定已审阅的题干参数，用独立枚举、模运算、矩阵和递推计算核对实际存储的答案；错误选项、错误数值或题干参数漂移会导致失败。这些有限检查不替代一般证明的学科审阅。

英文译文校验要求与原包编号完全一致，选项键、顺序和选择题答案不变，数组字段不遗漏条目，显示字段无残留中文。修改中文正文时，先同步更新并复核相应英文条目，再更新该条目的来源摘要；不能只刷新摘要绕过译文复核。这些检查不证明自然语言翻译或数学证明完全正确。

概念详情不再单独展示典型例题；全部358条例子已按逐条审核的题干改写为练习，使用稳定编号 `q-example-<concept_id>`，加入对应概念的关联练习。题面仅给条件和所问内容，原中英文例子完整保留于答案，解析另附原概念说明。`concept.example` 仍保留作来源兼容及摘要核对，不作为第二个可见例题区。新练习采用“简单／中等／困难”；旧练习的“基础／进阶”继续保留，并分别按简单／困难排序，不改变既有练习记录。

0.5.0将213道仍引用总概念的题目逐项归入细分概念；所有题目均只以细分概念作为所属概念，图谱模块仍从这些概念的父模块生成。新增“常系数线性齐次的定义与叠加”和“顶点强度与加权握手恒等式”两个细分概念及各一道练习，现有917道题的编号与中英题干、答案、难度全部保留。当前共358条概念、919道练习；总概念页保留概念层级，关联练习在细分概念页及图谱模块中展示。

复核或更新迁移题干后运行：

```sh
python scripts/migrate_concept_examples.py
python scripts/migrate_concept_examples.py --check
python scripts/test_offline_example_migration.py
```

该脚本从审核清单重建源题目、英文分片、来源摘要及静态副本；原例或原英文素材发生变化时会要求重新审核，不能静默覆盖摘要。原561道题的编号、题干、答案及其他元数据由清单中的逐记录摘要保护；如需另行修改旧题，须单独复核并更新兼容基线。

概念与练习使用和在线 AI 回答相同的 Markdown、LaTeX 保护、MathJax 与正文排版。中英文切换保留当前选择、筛选、搜索和参考答案展开状态；英文资源随离线外壳缓存，无需在线翻译请求。

概念库和题库的搜索只匹配中英文标题，不检索编号、正文、答案或分类；章节、难度、题型及勾选状态使用各自筛选。手机和平板将列表延伸至底部，通过“完整查看”打开所选条目的全屏详情，关闭后保留列表位置、详情滚动和参考答案展开状态；电脑保留左右分栏。

内容变更还应升级 `static/offline-service-worker.js` 的缓存版本，让已安装的离线版本取得新包。浏览器回归在实际断网后检查概念与题目互相跳转、答案展开、原有练习记录和本机保存。

## 双语内容、来源与商业发行

中文正文采用中国大陆本科离散数学常用术语；英文译文翻译 DMate 自有内容。两种语言保留相同的标准数学含义、内部编号及答案键，不夹入第三方教材段落。仅覆盖离散数学课程主题。

本包的中文定义、说明、例子、题干和解析独立编写；公开教材用于核对数学事实、课程范围和定理适用条件，不直接翻译、摘录或导入教材习题。参考资源的许可不被套用为本原创包的许可，项目自有内容的发行条款由项目权利人确定。若未来复制或改编第三方作品，必须改记实际来源并满足其署名、相同方式共享或其他义务；非商业或来源不明的题目不得混入商业离线包。

有限计算例已用程序核对，来源、结构与关联有自动检查；尚未完成独立教师逐条终审。具体核验记录和第三方许可差异见 [来源说明](SOURCES_AND_LICENSES.md)。
