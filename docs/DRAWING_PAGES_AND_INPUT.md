# 独立绘图与输入界面调整

独立绘图入口位于右侧菜单“绘图”，图片上传和识别工作区保持分离。菜单上方为“错题本”和“笔记本”，留出间距后依次为“知识图谱”“绘图”“学习报告”。

## 画板

- 一个画页对应一幅图；旧版本保存的多个子图迁移为分别可访问的历史画页。
- 新建空白页、命名、自动保存、历史切换；不再提供底部保存按钮。编辑350ms后写入，切换画页、关闭和离开页面时立即保存。历史可全部删除，空历史显示“无”，名称留白；版本2空图库不会重新导入旧文档。作品保存在当前设备，账号之间使用不同存储键；存储失败明确显示。
- 左侧选择/移动、添加顶点、添加边可收起；空图库仍可点击“绘图工具”开始绘制，用户主动点击后才创建画页，关闭或重新打开工作区不会自动重建历史。删除顶点及关联边或单独删除边均点击一次完成，支持撤销。
- 移除批量编辑、子图管理、图形框选及描绘显示开关。图形结构信息打开后完整显示。
- 导出独立 PNG，仅包含绘图；保留节点、箭头、重边、权值与真实边名。手机网页提供图片预览和下载，支持安装版相册桥接。
- 顶部使用汉字“上传”，调用 `/drawing/upload` 登记 PNG 与用户实际绘制的结构，不重新调用视觉模型。导出裁剪后同步转换结构坐标，放入原有图片发送区，用户点击发送箭头才确认并解题。空白绘图和上传失败明确显示错误。
- 右侧“AI指导”通过 `/drawing/guide` 读取本画页和可选要求，提供画图指导。NetworkX 只计算现有结构事实；DeepSeek 单次回答。不会修改画图。请求按钮使用聊天框同款加号。画页或要求变化后旧回答失效。
- “历史绘图”位于顶部，紧邻“新建空白页”，逐行删除使用红色圆形按钮，仅显示名称，不再显示点边数量。右侧的绘图设置、图形信息和 AI指导横向并排。绘图工具及这些面板共用信息选择框的浮动样式，标题栏不再设红色关闭按钮；点击入口、外部或 Escape 收起，各浮动框紧贴自己的入口按钮并限制在可见视口内。绘图设置仅保留方向与权值选项，名称使用顶部输入框。
- 绘图图形信息与上传识别共用 `DMateGraphFormat.renderGraphInformation`，使用同一格式和样式，包含类型、顶点、位置、外观及关系。信息跟随模型实时更新，新增、删除、重命名和撤销重做后不需重新打开面板，不重置画布位置。
- 新建空白页的图形标题与页面名称一致；旧历史中“绘图 N／我的图形”的默认名称差异仅同步通用标题，保留真实名称和图形结构。
- 新的无名顶点显示为1、2等普通数字，原图没有印刷名称的顶点仍保留 `label:null`；旧签名不修改。顶点属性中不再显示临时编号说明。
- 折线先绘制所有对比描边再绘制线条，作用点透明，不再切断拐点。图形与文字的不规则框可抓取任意边段局部拉伸，逐帧原位更新预览，松手后只识别一次。
- 自环可选中后拖动外侧控制点，调整大小和方向，保留为一条自环；位置使用已有 `edge.path` 布局字段保存，导出与上传沿用相同几何数据。关闭属性仅收起面板，保留所选边及控制点。
- 同色实线合并为连续路径，普通弧线和自环使用平滑曲线，保留阴影区域的自适应对比描边。添加边时显示较大的端点选择圆圈，使用固定屏幕尺寸并选择最近的顶点，实际点的显示大小保持稳定。选择圆圈不进入导出图片。

- 绘图“适应”使用实际绘制的点、线、曲线、自环、权值和标签边界缩放并居中；选择圆圈不计入边界。操作只改变相机，保留图形坐标与结构。原图片的适应行为保持原样。

## 其他交互

- 对话信息使用透明文字容器，不单独绘制底色、边框或卡片留白；删除当前对话后显示“无”，其他历史保留；刷新和云端合并不会自动打开另一段对话。
- 图片识别主弹窗固定在视口内，先完成不可见的模态布局，再显示并聚焦关闭按钮，用于网页识别编辑界面的稳定显示。点击上传首先打开浏览器提供的系统文件选择器，它与识别编辑、分组等网页弹窗相互独立，位置由浏览器和操作系统控制，网页不指定系统窗口位置。上传触发回归验证实际输入控件、按钮和键盘入口每次仅产生一次选择器事件，空选择返回后不重开；这些用例拦截原生选择器，不能验证操作系统窗口坐标或声称修复其显示动画。图片识别结果没有内层折叠或关系省略；编辑弹窗只在内容区滚动，右上角红色关闭按钮固定在标题栏。
- 笔记本去掉静态解释、默认选择、取消选择及撤销删除；选择概念使用较大的实心圆指示。搜索框有输入时使用红色实心圆清除按钮，不显示浏览器自带的×，点击后清空搜索并保留笔记和选择状态。每个概念行右侧提供红色圆形删除按钮；删除确认弹窗只保留删除操作与右上角红色关闭按钮，不另设“取消”按钮。
- 语音不再显示底部常规提示，麦克风状态和首尾缓冲保留；空结果、录音过短或转写失败会静默恢复待输入状态，保留输入框内容，后端错误状态仍如实返回。
- 普通输入框可自动扩行，单行高度调整为桌面52px、手机48px；底部留白，发送为主题色背景、白色箭头。输入框及各类按钮不显示蓝色或红色焦点外圈，键盘操作使用控件本身的亮度反馈。
- 绘图和笔记本的 AI 正文共用错题本的 Markdown 清理、数学公式保护及 MathJax 渲染路径和样式。公式渲染全局排队，旧结果与关闭的面板不会继续更新；笔记原文仍为普通文字输入。
- “取消分析”使用红色圆形按钮，取消后静默恢复；不再显示分析开始和取消后的常规说明，实际错误与 AI 正文保留。
- 笔记为空时仅显示新建概念、搜索及“无”，隐藏选中数量和AI操作；“AI 阅读”标题始终不显示。错题本空状态同样为“无”，聊天输入提示为“询问DMate”。

单张图片上传上限为20,000,000字节，详见 [千问上传限制](QWEN_IMAGE_UPLOAD_LIMITS.md)。

外观初始及恢复默认采用“跟随系统”，已有明确主题选择继续保留。界面面板透明度统一作用于各面板背景，保留文字、操作控件、原图片和绘图像素的不透明度；聊天气泡继续使用独立设置。对话信息、空状态、登录提示与背景预览分别使用“对话信息”“无”“未登录时不会保存信息”“无”，学习记录去掉错题数量说明，错题本统计不再使用间隔圆点。
