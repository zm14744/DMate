# 学习报告

报告在浏览器内汇总当前保留的学习数据，不新增模型请求。

- 题目记录沿用会话题目历史：明确的题目标记生效，同组多图按一题统计，同一对话内相同题干去重。
- 错题分为待订正、待复测、已通过复测；优先入口打开对应错题。
- 概念笔记只统计已填写名称或内容的记录，并排除已删除笔记。
- 知识追踪列出题目、求助和错题对应的知识点，提供图谱入口。
- 原题档案可按手动输入、图片与绘图题、AI 出题筛选，并定位原会话消息。
- 最近活动使用实际事件、错题状态和笔记更新时间，不给缺少时间的历史消息编造日期。

打开报告不修改原始会话，学习统计保留原有“是否题目”和分组口径。移动端使用双列概览和单列详情，内部滚动；面板透明度沿用外观设置。
