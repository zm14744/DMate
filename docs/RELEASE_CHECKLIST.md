## 1. 自动/离线检查

- [ ] Python 6 个源文件能通过 `python -m py_compile app.py ai.py teaching.py ocr.py graph_recognition.py classification_semantic.py`。
- [ ] `node --check static/script.js`、`node --check static/service-worker.js` 不报语法错误。
- [ ] `knowledge_graph.json`、`static/manifest.webmanifest`、`desktop/src-tauri/tauri.conf.json` 可解析。
- [ ] 若以后补充 `tests/`，运行 `python -m unittest discover -s tests -p 'test_*.py' -v` 并保存完整日志；当前源快照**没有**该测试套件。

## 2. 在线服务与数据安全

- [ ] Zeabur 当前提交部署完成；`GET /health` 返回健康信息；`GET /ready` 的 Web/OCR 状态符合预期。
- [ ] 环境变量、SMTP/Brevo 密钥、PostgreSQL URI、Snap Store 密钥未进入前端、日志、文档或打包产物。
- [ ] 新用户注册、邮件验证码、登录退出、密码恢复、账号注销均在隔离的测试账户上验证。
- [ ] 同一账户跨浏览器同步会话/错题/外观设置；制造 revision 409 冲突，验证前端自动合并、保留双方聊天分支、不发送 `force=true`；游客数据隔离且背景图片不上传。
- [ ] 验证 `/sync` 的大小边界：内部 `12 MiB` 阈值与 Flask 全局 `8.5 MiB` 请求上限冲突，按当前实际生效阈值记录 HTTP 413，并把双重限制列入代码修复清单。

## 3. AI 教学、出题与 OCR

- [ ] “这题不会做”先提示；“给完整解析”提供解题步骤；简单概念提问不误判为正式题目。
- [ ] “出一道题”确实生成题面；“出一道题并给出答案”同时返回题目和答案，不只输出题面。
- [ ] 普通出题、参照题出题默认中等；错题本复测默认继承原题难度（简单/中等/困难）。核对实际题目考点与答案完整性，不因分类器估计难度偏差拒绝有效题；复测偏档可以限次纠偏。
- [ ] 图同构、二部图、拓扑排序、CRT/模逆、递推关系、哈斯图等至少各有代表题核验分类与解答。
- [ ] 普通同知识点出题不偏到无关考点；多知识点错题复测核对 `retest_core_points` 全部被覆盖（目前最多 4 项），不因只交叉命中一个就放行。
- [ ] OCR 覆盖文字截图、公式截图、带顶点标记图、无标记纯图、非题目图，识别中撤销按钮为独立圆形红按钮；识别失败可恢复输入。

## 4. Web、复制、PDF 与图谱

- [ ] Edge/Chrome 与 Firefox 深色、白色主题均清晰；界面不出现白底白字。
- [ ] 手机输入框固定底部且弹出键盘不遮挡；左右抽屉可顺滑打开；图谱可见文字、可缩放拖拽且不超框。
- [ ] 文本与公式按实际渲染结果复制、支持局部选择；图谱图片复制/保存有可用后备路径；复制入口不重复。
- [ ] 错题本单题复制与 PDF 导出正确；重复复测不会让同一错题在同一 PDF 内重复出现。

## 5. 各安装渠道分别验收

- [ ] Windows Tauri：安装、启动、剪贴板、远程网页更新；若只更网页不应声称 EXE 本体自动升级。
- [ ] Linux DEB / AppImage：在目标发行版分别安装/启动；Snap `amd64` 在具有 `snapd` 的目标环境验收，单独核实 Store 渠道。
- [ ] Android：网络启动、文件/图片选择、系统返回键、底部输入框、图谱与复制体验；原生 APK 变化必须重构。
- [ ] iOS Safari：添加到主屏幕、PWA 图标、在线更新与离线缓存边界；不要把 PWA 称作 IPA 或 App Store 上架。
