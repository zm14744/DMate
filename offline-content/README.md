# DMate 离线学习内容包（预览）

本目录是离线模式的首批内容样例，当前只覆盖离散数学核心内容。

## 当前样例

- `concepts.zh-CN.json`：14 个中文概念条目。
- `questions.zh-CN.json`：14 道中文练习题，包含答案、解析、难度、知识点关联和评分要点。
- `SOURCES_AND_LICENSES.md`：来源筛选、许可边界和后续导入规则。
- `PREVIEW.zh-CN.md`：适合直接阅读的内容预览。

## 中文标准

面向用户展示的标题、定义、解释、例题、题干、答案、提示和解析均使用简体中文。只保留数学符号、公式和内部数据编号；不把英文原文或英文括注展示给用户。

术语以中国大陆本科离散数学常用表述为准，例如“命题、量词、二元关系、反对称、等价类、偏序、连通分量、握手定理、鸽巢原理、数学归纳法”。若来源采用不同译法，先核对数学含义，再决定是否采用，不机械照搬。

## 与现有知识图谱的关系

每个概念使用现有 `knowledge_graph.json` 中的节点编号，例如 `logic_truth`、`relation_equivalence`、`graph_basic`。这样题库、概念库、知识图谱和错题本可以共享同一知识点标识，不再维护重复的章节体系。

## 许可状态

本预览的题干、定义和解释是为 DMate 独立编写的草案，没有直接复制教材段落、插图、题目或解析。它们的正式发布许可和作者权属仍须由项目方确认；本目录不是法律意见，也不表示已经完成最终商业发行审查。

第三方开放教材不会直接混入本预览。未来如导入翻译或改编内容，必须逐条记录原作者、版本、来源、许可证、改动情况和审核记录，并按许可证分包。

## 质量状态

本预览用于评估内容结构、中文表达和产品交互，不等于完整题库，也未经过独立教师审校。正式发布前应至少完成：

1. 数学正确性复核。
2. 中文术语一致性复核。
3. 证明过程和评分标准复核。
4. 知识点映射复核。
5. 来源与许可证逐条复核。
