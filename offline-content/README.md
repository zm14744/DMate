# DMate 离线学习内容包

本目录保存完整简体中文的离散数学概念与练习；实际数量和各章覆盖见自动生成的 [覆盖清单](PREVIEW.zh-CN.md)。

## 文件

- `concepts.zh-CN.json`：课程大类概述与独立的细分概念，含定义、说明、符号、例子、易错点与关联练习。
- `questions.zh-CN.json`：分层练习、答案、解析、评分要点及精确的概念关联。
- `references.zh-CN.json`：本次联网核验的原项目、固定修订、参考章节和商业许可证据。
- `SOURCES_AND_LICENSES.md`：原创内容与第三方作品的界限、商业分发和未来改编规则。
- `PREVIEW.zh-CN.md`：从实际 JSON 生成的逐大类覆盖表。

## 内容层级和兼容

根目录 `knowledge_graph.json` 定义课程大类；每个大类下还需要多个具体概念。大类概述保留原节点编号，细分概念使用独立编号，并通过 `graph_node_id` 归属到图谱节点。概念前置关系使用概念编号；题目的 `knowledge_points` 指向实际考查的概念，`graph_node_ids` 由这些概念自动推导。

大类概述可以浏览细分概念和该大类全部练习，细分概念可以返回所属大类并打开关联题目，题目也可以返回所考查的概念。原有 `q01`–`q14` 编号继续保留，以兼容本地练习和错题记录；本次没有更换 IndexedDB 数据库或清除用户数据。

## 编辑、同步和检查

以本目录的两份内容 JSON 为编辑源，不直接编辑 `static/offline-content` 副本。修改大类结构、概念或题目后运行：

```sh
python scripts/sync_offline_content.py
python scripts/sync_offline_content.py --check
python scripts/test_offline_content.py
python scripts/test_offline_content_math.py
```

脚本验证大类覆盖、每类至少三个细分概念和八道分层练习、前置关系无环、题型与答案字段、精确概念关联及参考章节；同时生成双向导航、覆盖清单与静态发布副本。内容减少或关联失效时检查会失败。调整原始内容时仍须自行复核数学正确性，结构检查不能证明自然语言题目及证明全部正确。

数学回归另外固定已审阅的题干参数，用独立枚举、模运算、矩阵和递推计算核对实际存储的答案；错误选项、错误数值或题干参数漂移会导致失败。这些有限检查不替代一般证明的学科审阅。

内容变更还应升级 `static/offline-service-worker.js` 的缓存版本，让已安装的离线版本取得新包。浏览器回归在实际断网后检查概念与题目互相跳转、答案展开、原有练习记录和本机保存。

## 中文、来源与商业发行

正文采用中国大陆本科离散数学常用术语；保留标准数学符号与内部编号，不夹入教材英文段落。仅覆盖离散数学课程主题。

本包的中文定义、说明、例子、题干和解析独立编写；公开教材用于核对数学事实、课程范围和定理适用条件，不直接翻译、摘录或导入教材习题。参考资源的许可不被套用为本原创包的许可，项目自有内容的发行条款由项目权利人确定。若未来复制或改编第三方作品，必须改记实际来源并满足其署名、相同方式共享或其他义务；非商业或来源不明的题目不得混入商业离线包。

有限计算例已用程序核对，来源、结构与关联有自动检查；尚未完成独立教师逐条终审。具体核验记录和第三方许可差异见 [来源说明](SOURCES_AND_LICENSES.md)。
