这些结果属于本地规则层回归；模型调用、PaddleOCR 初始化、邮箱投递、数据库同步与安装包端到端运行仍须在对应环境验证。

## 5. 上下文与复测关键历史回归

历史记录包括：

- “上一道题再讲一下”切回上一有效题；
- 切换到历史题后输入“继续”仍围绕该题；
- “第一题”“第二题”定位到指定历史题；
- “集合那道题”等主题指代定位对应题目；
- AI 生成题进入历史题导航并恢复教学分类；
- “为什么 / 再解释一下 / 继续”不被误当新题；
- 未订正错题不能直接复测；
- 完成订正后生成同核心知识点、不同题面的复测题（为历史验收记录；新版增加知识点一致性检查，仍需人工端到端验证）；
- 正确 / 错误复测答案进入答案诊断并记录结果；
- 删除会话后，学习回顾不继续展示已删除会话产生的孤立事件。

当前实现还支持倒序题号、前后多步、第一 / 最后 / 当前题、组合导航，并区分大题内部“小题 / 问”与会话历史题号。

## 6. 当前核心验收链

```text
文字题 / 图片题 / AI出题
→ 题目对象登记
→ 知识识别 + 三档难度
→ 提示式辅导
→ 完整解析（明确要求时）
→ 记为错题
→ 完成订正
→ 结构化参照生成复测题
→ 提交复测答案
→ 答案诊断
→ 记录复测结果
```

## 7. 账号与同步新增验收重点

当前版本新增能力建议在每次发布前至少人工走一遍：

```text
邮箱验证码注册
→ 自动登录
→ 恢复码复制保存
→ 新建对话 / 错题 / 外观修改
→ 另一浏览器登录并拉取云端
→ 制造 revision 冲突并检查提示
→ 退出后页面清空进入游客模式
→ 邮箱验证码重置密码
→ 恢复码重置密码
→ 旧 Session 失效
→ 注销账号
```

邮件链建议分别验证 Brevo 主通道和 SMTP 备用通道。
