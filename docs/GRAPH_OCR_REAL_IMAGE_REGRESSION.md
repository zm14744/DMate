# DMate 图论图片识别：十批样本问题归因与真实回归验收

> 整理时间：2026-10-22。资料来自用户独立上传原图后的实际 DMate 识别记录，以及人工逐图核对。
> **本文件是回归计划，不是通过报告**；单元测试成功、HTTP 200、视觉模型调用成功均不能代替真实原图的拓扑正确性。

## 六维验收标准

| 维度 | 必须检验 |
| --- | --- |
| 1. 点和边 | 顶点数及标签；每条边的真实两端、方向、平行重数、自环、权值；保留孤立顶点 |
| 2. 题目文字 | 题干逐字、符号上下标；顶点/边名不得被当作整段题目；原图没有题干时不得杜撰 |
| 3. 渲染 | 实际核对弹窗完整截图；符号/LaTeX、换行、滚动、边名和权值 |
| 4. 图形描述 | 与边表一致；边不完整时不推导全图性质；未知关联点不称为孤立点 |
| 5. 描述统一 | 顶点、边、属性、状态与不确定项采用统一顺序和语义 |
| 6. 分图分隔 | 独立图数量、顺序、标题/图号与结构一一对应；一张图的孤立点和多个连通分量不得拆出新图 |

每个维度记录：通过／部分通过／不通过／无法核实。任何涉及结构的错误，不可因模型置信度高或边数相同而判定通过。

## 稳定复现过的错误类别

1. **P0 顶点与线迹拓扑**：真顶点遗漏、无节点交叉处换线、经过真节点不拆边、长斜线/曲线端点错连；代表：MIT 八顶点、康奈尔双图、上海交大复杂图、中国海洋大学 180525 G3、Petersen。
2. **P0 有向边**：箭头反向、单向边错当双向弧、同向平行弧错当反向边；代表：中国海洋大学 180441、10.10、南京大学题、连通性三图。
3. **P0 重边和自环**：误把不同边识别成重边、端点逆序重复、弧线误判自环；代表：图 11.18、12.10、14.28、康奈尔、会津大学。
4. **P0 带权图**：数字权值误当边名，正确数字绑定到错误端点，漏虚线边；代表：14.21～14.28 及 (a)～(d)。
5. **P1 图形分隔与归属**：不连通图拆图、孤立点拆图、同一原图多个分图乱序；代表：180744、181000、图 10.8(b)、180506、图运算六图。
6. **P1 识别/核验/展示状态**：候选边存在却显示零条已确认边与所有顶点孤立；声称简单图但包含环/重边；边集虽正确却反复显示不一致的已核对/待核对；代表：欧拉图五图、会津大学。
7. **P1 OCR 与图形标签分离**：纯图形照片只识别出顶点/边号，正文乱码、无关页码；代表：多张教材实拍图、MIT 电子题、中国海洋大学。
8. **P2 输出及渲染统一**：有时输出结构化表，有时输出调试坐标，公式和置信度提示不统一；须查看实际弹窗，不得根据接口 JSON 猜测。

## 真实验收的唯一有效流程

1. 人工独立从**原图**建立 ground truth：顶点、边多重集合（方向和权值不丢）、图数、图顺序、题目文本。
2. 使用**同一原始图像字节**上传已部署 DMate；保存请求哈希、部署版本、原始 `/ocr` 响应。
3. Playwright 打开实际 OCR 识别核对弹窗，保存最终可见的文字、图形描述和完整截图。
4. 自动比较：有向图采用 `(from,to,weight,edge_label)` 的多重集合；无向图对端点排序，但**必须保持实际平行边重数**；分图按原图相对位置一一对应。
5. 比较真实 OCR 题干与 UI 渲染；任何未完成审核必须显式列为未通过，不能只检查接口状态。
6. 修改代码后原图重传，先检查上述失败样本，再保护斯坦福六树、MIT 四图、教材 13.11/14.22 等正例。

## 代码层次的排查顺序

1. `graph_recognition.py`、`graph_recognition_v2.py`、`graph_line_tracer.py`：顶点定位、曲线/交叉路径完整性，像素证据。
2. `graph_arrow_evidence.py`：箭尖像素与独立路径的终点对应。
3. `graph_detector_consensus.py`、`graph_evidence_fusion.py`、`graph_validation.py`：跨检测器对应、方向和重数校验、未知与不存在的区别。
4. `ai.py`：视图裁切、模型结构识别、权值归属、分图原始排序。
5. `app.py`、`graph_ocr_cleanup.py`、`static/script.js`：题干清洗、核验状态、显示一致性和图形归属。
