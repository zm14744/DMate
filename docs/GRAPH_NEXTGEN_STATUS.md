## 保留的架构与本次修复

- 继续使用 PP-DocLayoutV3、PP-OCRv6 Small、DeepSeek、Qwen3-VL-Plus；不替换大模型或升级服务器。
- 保留 NODE → EDGE → TRACE → 关系联合选择 → REVIEW。最多8幅图、48个顶点焦点、7次远程调用、155秒视觉阶段预算；未知方向、缺失权值及不完整结构不自动认证。
- 修复越界曲线路径采样导致实际 `/ocr` 崩溃回退的问题。
- 来自同一顶点的多条近邻平行观察分别保留 ID；只对来自另一个端点的观察作一对一匹配。缺失权值不覆盖已有值，冲突值保留内部证据。
- 加入填充箭头的像素锥度候选；将方向冲突传入局部复核。像素证据不直接强制翻转方向。
- 粗定位端点移动时按弧长同步移动整条候选路径，保留原观察路径，避免中段仍偏移而无法关联真实箭头像素。
- 在同一原始笔画上偏移的直线/骨架探测，通过真实墨迹间隙检验去重；不同平行线之间的白色走廊保护独立重边。
- 教材照片使用有界尺寸的光照归一化分离深色正面笔画与纸面阴影，避免固定灰度阈值把整页识别为线条。原图仍是视觉阶段的第一张输入，归一化图只作辅助。
- 仅当圆点候选与 NODE 清单冲突时增加一次有预算的视觉复核；像素圆点不直接添加顶点。复核失败保留旧清单并标记不完整。
- REVIEW 显式传递每幅图的有向/带权属性，防止将无向边的“确认”误写成 forward。未解决的类型冲突保留 unknown。
- 严格解析完整 JSON；不从截断响应里捞取一个内部边对象冒充成功。EDGE 使用共享边池减少重复输出。多图 REVIEW 覆盖后面的分图；单图剩余复核预算用于箭头冲突。
- 根据剩余调用预算缩小密集 EDGE 批次，保留两次 REVIEW 和7次总调用上限；实际18点多图批次由12+6改为6+6+6，避免一批超时丢失大部分观察。候选按共享端点分组送给复核，明确分组不是重数真值；同一笔画只选一个ID，不同平行笔画分别保留。
- 图形描述、卡片使用统一边身份、方向和权值。内部不确定性保留；用户卡片不显示像素候选编号或无意义技术套话。编号顶点标签使用 MathJax 下标格式。
