## 实际实现

|环节|实现与保护|
|---|---|
|全图 Qwen|明确要求顶层对象 `{"coordinate_space":"original_1000","graphs":[...]}`；顶点、路径、图范围统一原图 0–1000 单位|
|边界解析|显式一次转换为内部 0–1；拒绝错误根类型、未知坐标协议、非有限数值、越界坐标、重复 ID 和不存在的端点；不猜单位、不提取内层 JSON|
|节点及墨迹|复用原图 OpenCV 定位与路径证据；近乎重合顶点标记为不确定，不擅自合并、删点或更名；不生成带错误强制编号的辅助图|
|局部选择|结合权值文字框、路径冲突、端点不匹配和重边选择一个局部；原图直接裁剪为 PNG，最长边不超过 1280，不缩放、不插值，不从全图缩略图二次裁剪|
|唯一一次复核|全图背景加原始局部，返回 `crop_1000`；每条候选有允许修改的字段。局部只覆盖权值时只能修改属性，不能删除整条边、改方向或路径；越权响应拒绝应用|
|边实例及来源|保留模型边 ID、原端点与方向、独立路径及来源。一条全图观察不伪造成两个独立端点观察；同端点平行边保持不同实例，像素候选不自动取得视觉置信|
|新增笔画|仅允许局部内已有端点，最多 8 条；复用原墨迹、途中顶点与重复笔画检查，不按图名、度数或同构结果补边|
|校验与输出|使用 NetworkX 多重图做身份/端点一致性检查，复用原文字处理与显示投影；NetworkX 不裁定照片是否识别正确|
|失败|首次输出失败停止；局部失败保留首次读取及原几何结果，标记未完成，不重试、不启动旧视觉回退。启用阶段审计时保留失败输出和实际 usage|

复用的 `graph_glm_adapter.py` 函数仅用于已有 CPU 前景/墨迹处理，没有 GLM 请求。
没有引入 VisAdj 神经网络、额外模型或依赖，没有改生产环境变量。
