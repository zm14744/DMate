# 独立绘图与输入界面调整

独立绘图入口仍在右侧菜单“画图”，图片上传和识别工作区保持分离。

## 画板

- 一个画页对应一幅图；旧版本保存的多个子图迁移为分别可访问的历史画页。
- 新建空白页、命名、自动保存、历史切换。作品保存在当前设备，账号之间使用不同存储键；存储失败明确显示。
- 左侧选择/移动、添加顶点、添加边可收起；删除顶点及关联边或单独删除边均点击一次完成，支持撤销。
- 移除批量编辑、子图管理、图形框选及描绘显示开关。图形结构信息打开后完整显示。
- 导出独立 PNG，仅包含绘图；保留节点、箭头、重边、权值与真实边名。手机网页提供图片预览和下载，支持安装版相册桥接。
- “上传到对话”调用 `/drawing/upload`，登记 PNG 与用户实际绘制的结构，不重新调用视觉模型。导出裁剪后同步转换结构坐标，放入原有图片发送区，用户点击“发送”才确认并解题。
- 右侧“AI 回答”通过 `/drawing/guide` 读取本画页和可选要求，提供画图指导。NetworkX 只计算现有结构事实；DeepSeek 单次回答。不会修改画图。画页或要求变化后旧回答失效。
- “历史绘图”位于顶部，紧邻“新建空白页”。右侧仅有绘图设置、图形信息和 AI 回答，面板采用红色圆形关闭。绘图设置仅保留方向与权值选项，名称使用顶部输入框。
- 新的无名顶点显示为1、2等普通数字，原图没有印刷名称的顶点仍保留 `label:null`；旧签名不修改。顶点属性中不再显示临时编号说明。
- 折线先绘制所有对比描边再绘制线条，作用点透明，不再切断拐点。图形与文字的不规则框可抓取任意边段局部拉伸，逐帧原位更新预览，松手后只识别一次。
- 自环可选中后拖动外侧控制点，调整大小和方向，保留为一条自环；位置使用已有 `edge.path` 布局字段保存，导出与上传沿用相同几何数据。关闭属性仅收起面板，保留所选边及控制点。
- 同色实线合并为连续路径，普通弧线和自环使用平滑曲线，保留阴影区域的自适应对比描边。添加边时扩大顶点的屏幕点击范围并选择最近的顶点，实际点的显示大小保持稳定。

## 其他交互

- 删除当前对话后停留“暂无对话”，其他历史保留；刷新和云端合并不会自动打开另一段对话。
- 图片识别结果没有内层折叠或关系省略；编辑弹窗只在内容区滚动，右上角红色关闭按钮固定在标题栏。
- 笔记本去掉静态解释、默认选择、取消选择及撤销删除；选择概念使用较大的实心圆指示。删除确认弹窗只保留删除操作与右上角红色关闭按钮，不另设“取消”按钮。
- 语音不再显示底部常规提示，麦克风状态和首尾缓冲保留；空结果、录音过短或转写失败会静默恢复待输入状态，保留输入框内容，后端错误状态仍如实返回。
- 普通输入框可自动扩行，单行高度调整为桌面52px、手机48px；底部留白，发送为蓝底白箭头。输入框及各类按钮不显示蓝色或红色焦点外圈，键盘操作使用控件本身的亮度反馈。
- 绘图和笔记本的 AI 正文共用错题本的 Markdown 清理、数学公式保护及 MathJax 渲染路径和样式。公式渲染全局排队，旧结果与关闭的面板不会继续更新；笔记原文仍为普通文字输入。

单张图片上传上限为20,000,000字节，详见 [千问上传限制](QWEN_IMAGE_UPLOAD_LIMITS.md)。
