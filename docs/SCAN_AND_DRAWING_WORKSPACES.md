# 图片识别与独立绘图

图片识别和绘图现在是两个入口：

- 右侧「学习工具」中的「绘图」打开空白画板。支持原有点边绘制、方向和权值设置、缩放、撤销重做。保存到当前浏览器，重新打开可继续修改，不创建图片识别任务，不调用模型，也不修改任何已有扫描结果。
- 上传图片后，每张任务左侧显示原图，右侧显示可修改的文字、只读渲染图以及点边关系，下方是可选解题要求。手机端依次上下排列，仍支持四张图片独立扫描。
- 「修改结构」打开节点、边、图类型与权值的表单，不进入绘图画板。修改同步更新扫描草稿和渲染图。
- 「确认识别结果」验证当前文字和图结构，确认后才出现「解题」。修改文字或结构会使旧确认失效；可选要求不改动已确认的数学结构。

千问思考模式的同一次主识别同时返回 `body_text` 和图结构；保留全部实际题干、小问、条件、公式与必要图例，无题干则返回空文字。没有为这一布局额外启动 OCR 或 DeepSeek 描述请求。按需局部复核和最终结构检查继续使用现有流程。

只读渲染复用编辑器已有的 SVG 生成逻辑，保留箭头、权值、重边、自环及匿名节点；预览不绑定点边编辑操作。未知方向以虚线及点边信息中的待核对标记展示。

验证包括桌面与手机上的左右/上下布局、只读图形、文字修改与重新确认、结构修改后重渲染、独立画板保存与重开及扫描隔离。真实 API 抽测：`oct21_014` 返回了原图完整作业题干和 11 条边，约 30 秒；`oct21_007` 返回空题干和 11 条边，约 20 秒。两张均完成单次主识别后的正常处理；此记录不替代完整准确率评估。
