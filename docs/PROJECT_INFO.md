## 产品定位

DMate 面向高校离散数学学习场景，以自由式 AI 交互为入口，将题目理解、知识关联、教学模式、难度分级、图片识题、AI 练习、错题订正、复测、知识图谱、学习回顾和多设备同步组织成连续学习流程。

## 当前产品能力边界

- 核心学习功能在未登录游客模式下也可使用；
- 游客数据为临时状态，不做持久保存；
- 注册登录后，会话、学习记录、错题、复测状态和外观参数可通过 PostgreSQL 跨设备同步；
- 自定义背景图片本体只保存在当前设备，不上传云端；
- 知识图谱目前为 10 个模块、68 个知识节点，用于课程组织，不计算或存储虚构“掌握度”；
- 具备图同构、二部图、拓扑排序、模逆 / CRT、公式型齐次 / 非齐次递推等代表性题型识别与三档难度校准；
- “同知识点出题”校验课程大类与可识别核心考点的一致性，但规则识别不能保证每一道题都正确；
- Windows / Android 采用远程网页客户端壳，网页与后端可在部署后更新；客户端原生代码未配备自动升级机制；
- 产品不训练自有大语言模型。

## 功能测试与覆盖（2026-10-08）

- 175 项个人功能自测表的状态列**默认预设为 175/175 项“通过”**，覆盖教学与练习、图片识题、知识图谱、错题与复测、富文本与公式复制、PDF、账号/邮件、云同步、移动端及部署等；此为**个人记录状态**，不表示本次已独立重测全部功能。
- 曾对最新版出题、难度语言识别、OCR 图片用途及移动端 OCR 交互执行 **27 项离线回归测试，记录为通过**；与线上真实模型和跨设备端到端验收分开统计。
- 重点功能还包括完整题目复制、错题单题富文本复制、公式局部高亮选取，以及知识图谱 PNG 图片复制（受设备剪贴板能力约束）。

## 技术定位

项目自主工作集中于：

- 离散数学场景的教学控制；
- 题目对象与历史题导航；
- 三档难度识别与出题控制；
- 生成题正式登记；
- 错题—订正—复测闭环；
- OCR / Vision 结构化输入编排；
- 知识图谱与学习记录组织；
- 账号、邮箱验证与多设备云同步；
- 前后端集成与部署。

运行时基础生成 / 识别能力来自 DeepSeek、PaddleOCR 以及可选外部文本算力通道；事务邮件由 Brevo / SMTP 提供，账号数据使用 PostgreSQL。
