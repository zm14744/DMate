# 原图上传与千问发送大小

单张图片上限为 **20,000,000 字节（20MB）**，与百炼当前 Qwen3.8 原图上限一致。
一次仍最多四张，每张独立上传、独立识别。前端与所有原图/图形框/文字框接口使用同一上限，
原图不会先被缩成预览图再识别。预览缩放只影响屏幕显示。

[百炼视觉理解官方说明](https://help.aliyun.com/zh/model-studio/vision)（2026-10-29 核对）区分了：

- Qwen3.8 编码前原图：不超过20MB。
- OpenAI兼容/DashScope的单张Base64 Data URI：不超过20MB。
- 工作空间域名请求体：不超过64MB；旧DashScope域名另有16MiB限制。
- 推荐原图分辨率：8K（7680×4320）以内；高分辨率使用JPEG/PNG。

因此不能把20MB原图无条件再转成更大的PNG/Base64发送。`image_upload_limits.py` 默认使用无损PNG；
只在PNG的Data URI会超限时，生成同宽高的JPEG发送副本，优先95质量，按有限序列降低编码质量，
直到Data URI符合限制。该过程保留图片尺寸，不裁剪、不缩小原图；原始文件及其哈希仍用于选区、
来源检查和后续确认。普通数学截图通常始终使用无损PNG。

原图解码上限统一为33,177,600像素（8K像素预算），避免初次上传成功而选区识别被旧的16/24MP限制拒绝。
本地OCR的独占调度、进程内存和运行时间约束继续生效。超出资源限制会报告失败，不会伪装为空白识别成功。

`tests/test_qwen_image_upload_limits.py`验证20MB原图原样抵达识别入口、各选区接口一致、超限拒绝、
Base64发送预算以及超过24MP原图的实际解码和裁剪。
