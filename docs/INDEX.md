## 按任务阅读

### 想使用 DMate

1. 从 README 的“第一次使用”开始，了解题目标记与默认提示方式。
2. 上传图片前，阅读使用指南中的“图片”相关章节，区分保存、发送、原生结果和自主来源。
3. 需要持续学习时，再阅读错题本、笔记本、学习回顾与账号保存说明。
4. 换设备或清除浏览器数据前，查看数据与隐私，确认哪些内容仅在本机。

### 想部署自己的服务

1. 按 README 安装 Linux / Python 3.10 依赖，或使用 Docker。
2. 按部署说明的功能配置表分别准备 DeepSeek、DashScope、本地 OCR、数据库及邮件。
3. 确认 Cookie、HTTPS、持久卷、模型缓存和进程数设置。
4. 需要改客户端域名或打包时，继续阅读客户端构建及 macOS 分发说明。

### 想维护代码或接入 API

1. 阅读架构中的模块入口和状态流，确认修改属于扫描、绘图、聊天还是学习整理。
2. 按 API 文档处理 Cookie、任务 ID、确认快照及错误，不自行拼造确认字段。
3. 识图相关修改以识别流程中的实际 `workflow` 为准，分别判断网页主线与兼容路径。
4. 调整数据结构或第三方服务时，同时更新使用指南、隐私说明与对应配置表。

## 几个容易混淆的区别

| 概念 | 应如何理解 |
| --- | --- |
| 扫描核对 / 独立绘图 | 扫描通过来源选择与重识别组合内容；画板直接编辑顶点、边与布局 |
| 保存 / 发送 | 保存确认当前内容；发送才创建对应聊天请求 |
| 题目标记 / 图片分组 | 前者决定是否作为正式题目记录，后者决定哪些图片合并为一道题 |
| 原生识别 / 自动工作流 | 原生识别是首次结果的前端名称，不是系统 OCR，也不是模型配置开关 |
| 账号同步 / 绘图保存 | 学习快照可同步；账号图库和背景图片本体只在本设备，游客绘图仅在当前页面 |
| 健康接口 / 功能可用 | Web 可响应不等于数据库、邮件、所有模型或识图结果均可用或正确 |
| 客户端 Artifact / 已发布版本 | 构建产物还需发布并被用户安装，网页更新不能替换原生代码 |

历史开发过程可查 Git 提交；当前说明不把已删除的阶段报告、旧基准结果或失效页面作为操作前提。有关依赖许可的原始依据，继续查看第三方许可和参考资料中的上游链接。
