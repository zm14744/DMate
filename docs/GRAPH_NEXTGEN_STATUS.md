开发分支：`codex/graph-ocr-nextgen-20261022`。草稿 PR：https://github.com/zm14744/DMate/pull/5 。未合并 main，未部署 Zeabur，未修改生产数据库。

## 本次私有材料

用户本次上传的 ZIP 已解压，55 个文件逐一读取并匹配清单 SHA-256：44 张题目原图、9 张历史实际 OCR 截图、2 张技术说明截图。后两张技术截图内容重复，但仍按两个原始文件登记。原图包括23张海洋大学课件、9张高校题、11张教材照片和1张补充题。

原始图片、独立标注、原图像素检查裁图、真实响应、Playwright 弹窗截图及 trace 保存在仓库外的私有目录；不公开提交教材或课件图片。裁图仅辅助检查，不作为新增测试原图。历史识别结果和技术截图不加入44张题目原图的准确率分母。

已有43张原图的逐边独立结构记录；其中一张教材小箭头仍有方向歧义，另有一张高校题因原图底部截断而不能完整标注。因此完整参考为42张；未确定的标签、位置、文字与公式仍标记未核实，不用模型输出补写正确答案。

仓库历史 corpus 只含此前两张可公开使用的原图，不代表本次私有55图。支持通过 `tests/nextgen_browser.py --corpus ... --capture-only --artifacts ...` 导入仓库外清单与证据；capture-only不代表准确率通过。

## 保留的架构与本次修复

- 继续使用 PP-DocLayoutV3、PP-OCRv6 Small、DeepSeek、Qwen3-VL-Plus；不替换大模型或升级服务器。
- 保留 NODE → EDGE → TRACE → 关系联合选择 → REVIEW。最多8幅图、48个顶点焦点、7次远程调用、155秒视觉阶段预算；未知方向、缺失权值及不完整结构不自动认证。
- 修复越界曲线路径采样导致实际 `/ocr` 崩溃回退的问题。
- 来自同一顶点的多条近邻平行观察分别保留 ID；只对来自另一个端点的观察作一对一匹配。缺失权值不覆盖已有值，冲突值保留内部证据。
- 加入填充箭头的像素锥度候选；将方向冲突传入局部复核。像素证据不直接强制翻转方向。
- 粗定位端点移动时按弧长同步移动整条候选路径，保留原观察路径，避免中段仍偏移而无法关联真实箭头像素。
- 在同一原始笔画上偏移的直线/骨架探测，通过真实墨迹间隙检验去重；不同平行线之间的白色走廊保护独立重边。
- 教材照片使用有界尺寸的光照归一化分离深色正面笔画与纸面阴影，避免固定灰度阈值把整页识别为线条。原图仍是视觉阶段的第一张输入，归一化图只作辅助。
- 仅当圆点候选与 NODE 清单冲突时增加一次有预算的视觉复核；像素圆点不直接添加顶点。复核失败保留旧清单并标记不完整。
- REVIEW 显式传递每幅图的有向/带权属性，防止将无向边的“确认”误写成 forward。未解决的类型冲突保留 unknown。
- 严格解析完整 JSON；不从截断响应里捞取一个内部边对象冒充成功。EDGE 使用共享边池减少重复输出。多图 REVIEW 覆盖后面的分图；单图剩余复核预算用于箭头冲突。
- 图形描述、卡片使用统一边身份、方向和权值。内部不确定性保留；用户卡片不显示像素候选编号或无意义技术套话。编号顶点标签使用 MathJax 下标格式。

## 测试证据及其范围

本地机制测试：86项 Python 测试通过。测试覆盖图像边界、箭头像素、重边身份、权值冲突、整条路径校正、纸面阴影、真实笔画间隙与 NODE 冲突复核。这些测试不等价于44张原图识别正确。

提交 `6ec31d2` 的 GitHub Actions：Graph Data Integrity（39801611336）、Graph OCR nextgen acceptance（39801611137）通过。此处CI包含历史两张公开原图的展示契约和资源检查，不是本次55张私有材料的真实识别验收。

真实 `/ocr` 与实际弹窗回归正在专用容器中执行。容器实测 `cpu.max=200000 100000`、`memory.max=4294967296`；PP-DocLayoutV3 和 Small 继续串行短生命周期运行。模型缓存通过官方HTTPS下载，保留TLS验证。Playwright公共CDN脚本采用固定URL、SHA-256校验的TLS下载缓存，`/ocr`没有Mock，浏览器信任库未更改。

`6ec31d2` 的真实结果已暴露180441方向翻转、180525错边、181129漏重边、教材14.21/14.22及照片(d)候选边膨胀等问题。HTTP200、弹窗成功和CI通过不能消除这些失败。v6修复必须在相同原图上重新执行后才能报告改善；不能将旧响应标成新提交的测试。

私有六维报告分别记录结构、题干、公式/界面、描述、格式和分图。无标签图仅同构匹配、仅分图数量相同或仅MathJax生成SVG均只算部分验证。完整端点、方向、重数、权值及原图阅读顺序未确认时不得报告全通过。
