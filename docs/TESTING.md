### 复制与数学渲染的专项检验点

- 聊天中仅完整题目出现题目复制入口，普通讲解、追问不会错误显示。
- 错题本逐题复制保留渲染后的文字、表格与公式，排除卡片操作按钮和隐藏控件；笔记界面不重复堆放复制按钮。
- 跨文字和 MathJax 公式拖选复制可正确混排；公式内局部拖选只复制所选字形，颜色反馈一致。
- 富文本粘贴支持时尽量保留公式的 SVG 视觉内容；纯文本粘贴合理降级到 LaTeX，并检查不同浏览器/目标软件的差异。
- 知识图谱复制产生真实 PNG 图片而不是节点文字；系统禁用图片剪贴板时以保存 PNG 作为后备路径。
- 错题 PDF 中公式能正常显示，同一道错题不被意外重复导出。

## 5. 上下文与复测关键历史回归

历史记录包括：

- “上一道题再讲一下”切回上一有效题；
- 切换到历史题后输入“继续”仍围绕该题；
- “第一题”“第二题”定位到指定历史题；
- “集合那道题”等主题指代定位对应题目；
- AI 生成题进入历史题导航并恢复教学分类；
- “为什么 / 再解释一下 / 继续”不被误当新题；
- 未订正错题不能直接复测；
- 完成订正后生成同核心知识点、不同题面的复测题（为历史验收记录；新版增加知识点一致性检查，仍需人工端到端验证）；
- 正确 / 错误复测答案进入答案诊断并记录结果；
- 删除会话后，学习回顾不继续展示已删除会话产生的孤立事件。

当前实现还支持倒序题号、前后多步、第一 / 最后 / 当前题、组合导航，并区分大题内部“小题 / 问”与会话历史题号。

## 6. 当前核心验收链

```text
文字题 / 图片题 / AI出题
→ 题目对象登记
→ 知识识别 + 三档难度
→ 提示式辅导
→ 完整解析（明确要求时）
→ 记为错题
→ 完成订正
→ 结构化参照生成复测题
→ 提交复测答案
→ 答案诊断
→ 记录复测结果
```

## 2026-10-08 后续代码修复专项（新增）

出题修复：无显式难度时不得因启发式分级差异返回 502；显式难度允许额外重试一次并可保留有效题，须在 UI 上核对目标难度与实际估计不保证一致。回归“大指数取模” `3^2024 mod 17` 归属初等数论/同余与模运算并判为中等，检查“不太难”“稍微难一点”等否定及程度表达。

OCR 修复：验证识别中电脑“图片识题”和手机“＋”按钮隐藏、空间补位且撤销保留；手机核对窗口底部两按钮固定，长文本/图形区独立滚动；非题目课件/照片明确判定返回 422 而不进入解题；纯图论题或不确定图不被简单误杀。

此前该修复轮次曾记录 **27 项离线回归通过**，仅代表当时执行的代码级测试，不代表真实 OCR、线上模型、跨设备和安装版全链路的人工验收。
