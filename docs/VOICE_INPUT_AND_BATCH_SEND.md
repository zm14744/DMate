# 语音输入与图片批量发送

2026-10-29

## 语音输入

主输入框右侧提供麦克风按钮。点击开始录音，再次点击结束并识别；识别结果插入当前输入位置，保留已有文字，由用户按发送按钮提交。录音最多60秒，可取消；麦克风启动前的权限和设备错误明确提示，空结果或转写失败静默恢复，后端仍返回真实错误状态。切换会话、打开编辑窗口、进入图片上传工作区或页面转入后台时会取消录音，不向其他会话写入迟到结果。

浏览器使用设备默认 AudioContext 采样率，转换为16kHz、单声道、PCM16 WAV，再调用 `POST /voice/transcribe`。后端检查文件内容、长度和采样规格，并使用现有 DashScope 凭证发起一次原生同步请求：

- 模型：`qwen-audio-3.1-asr-flash`
- 词库：`vocab-dmate-60d8d29883164a5a83fdfbb7f21772a9`
- 路径：`/api/v1/services/aigc/multimodal-generation/generation`
- 词库参数：`parameters.vocabulary_id`
- 默认复用现有 `DASHSCOPE_API_KEY` 和视觉服务工作空间主机；也兼容 `DASHSCOPE_VISION_API_KEY`。
- 可选配置：`DMATE_ASR_MODEL`、`DMATE_ASR_VOCABULARY_ID`、`DMATE_ASR_API_URL`。服务路径由程序固定，不将凭证提供给浏览器。

接口不会调用聊天解题，不自动切换模型或丢掉词库重试。并发容量为每工作进程2个，语音独立限流使用现有限流器（默认每身份每分钟10次）。应用不把录音保存为聊天附件或持久化业务记录。

浏览器封包使用批量PCM复制，重采样直接写入类型数组，保留原插值、舍入和全部样本。350ms尾音采集及150/250ms首尾静音保护不变；逐样本和完整WAV字节回归覆盖九种设备采样率及不同分块。Chromium同进程交替基准中，60秒音频WAV封包中位耗时10.2→5.3ms，48kHz重采样CPU耗时59.0→34.7ms；这是客户端处理开销，不代表整个识别请求缩短了数秒。

后端按线程及进程复用HTTP连接，每次使用独立Authorization并清空cookie，保留环境代理与CA校验。仅复用连接，不预热额外请求、不重试POST、不缩短超时；请求异常后丢弃连接。真实本地HTTP/1.1回归验证同线程两次请求使用一条连接。成功响应的 `timings_ms` 包含 validation、preparation、provider、parsing、total；provider是包含网络和服务计算的整个请求往返，不能当成纯模型推理时间。首次请求仍需建立连接，实际端到端收益需结合网络和服务耗时评估。

本轮使用既有3.48秒合成语音实际调用5次相同模型和词库，5次转写完全一致。排除一次预热后，原请求方式两次为4.072/2.173秒，连接复用两次为7.166/3.186秒；本地校验、准备与解析合计不足0.7ms。样本较少且服务往返明显波动，本轮没有证明稳定的端到端提速，也不能由此判定稳定变慢；不以客户端CPU优化或连接复用测试宣称识别快了几秒。私有音频、转写和请求凭证不提交仓库。

当前原生HTTP接口接收完整音频；官方说明仅在音频不少于1分钟时才分批返回SSE中间结果，不能借此减少当前短录音的输入等待。[实时输入协议](https://help.aliyun.com/zh/model-studio/asr-model)使用不同模型ID，需独立验证数学词汇和识别效果，本次不自动切换。

官方接口说明：<https://help.aliyun.com/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api>

## 图片编辑与发送

- 编辑窗口默认选择模式。点击时轻微抖动不触发平移；画布扩展按真实偏移补偿，避免首次选择跳动。
- 删除原来的初始调试说明和要求输入框示例提示，仍保留边方向未知、选区失败等真实状态。
- 右下角为“保存”。保存只校验当前结构并退出编辑窗口，不产生聊天消息或解题调用。
- 图片工作区复用原生上传控件和发送按钮，显示加号和发送箭头。每批最多4张图片，识别独立进行；右上角分组设置逐张选择是否为题目及组别，默认各自成组。同组按上传顺序作为一个聊天请求提交，独立组依次分别回答。
- 直接发送尚未保存的识别结果时，先逐张完成同样的结构校验和原图签名确认。任一图片尚在识别、失败或校验不通过，整批不提交给解题模型。
- 每组的 `semantic_contexts` 保存成员原有确认令牌。服务器逐一验签，并对图使用 `imageN_graphM` 命名空间；解题期间任何成员被修改，旧回复也会失效。图片编号在组内计算，引用采用“图片2的图1从1到2”，不同组不共享计算结构。
- 整批内容过长会明确报错，不截断题干、图例或图结构。后续追问、会话保存及云端合并继续保留同一批确认快照。

## 客户端与验证

浏览器麦克风需要 HTTPS 和用户授权。旧安卓安装包的 WebView 代码直接拒绝麦克风，网页更新无法改变这一限制。本次已在 Android 源码中添加可信 DMate 来源的麦克风运行时授权，保留系统图片选择和相册保存功能；旧安装包需要换用包含该代码的新客户端，或使用浏览器。没有修改版本号或自动发布安装包。

新增回归覆盖录音和取消生命周期、采样转换、词库及模型参数、真实错误响应、编辑选择与保存位置、四图一次发送、重复点击、逐图验签、存储追问及跨图片引用。桌面、手机浏览器均执行交互测试。另使用3.48秒合成语音发起真实模型调用，携带上述词库返回识别文字，耗时3.822秒；识别保留了实际单词误差，未声称零错误。真实音频及私有返回不提交仓库。
