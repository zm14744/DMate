# DMate 使用指南

DMate 的主要工作区包含对话、输入区和学习工具；手机上通过侧栏打开对话列表与学习工具。AI、识图、语音、账号和云同步需要联网。

## 开始对话

1. 点击“新对话”，在输入框输入问题。需要记录为一道正式题目时，将输入框上方“题目”设为“是”；普通讨论设为“否”。这个选择不会被题干中的关键词覆盖。
2. 点击发送。电脑上 Enter 发送、Shift+Enter 换行；手机回车换行。输入框随内容扩展，长内容在框内滚动。
3. 解题默认先给知识点和提示。需要最终结果时明确写“完整解析”或“给出答案”；也可请求概念解释、检查自己的答案，或生成简单 / 中等 / 困难的练习。
4. 回答期间可点击红色停止按钮。继续追问时可说“当前题”“上一道题”“第 2 题”，或直接针对当前题询问；题目定位不明确时补充题干或编号。

明确的“题目：否”不新增题目档案；已有题目的正常追问仍可关联学习支持记录。AI 出题可以进入题目历史，但生成题目不代表已经作答。难度与知识分类是辅助判断，生成题目也可能需要核查。

## 语音转文字

点击麦克风开始录音，再次点击结束并等待转写。文字插入当前光标位置，可修改后发送，不会自动提交。单段最长 60 秒；录音和转写完成前不能发送尚未收齐的输入。

麦克风需要 HTTPS、浏览器支持和设备授权。切换会话、打开编辑器、进入图片工作区或切到后台会取消录音；迟到结果不会插入其他会话。空结果或转写失败会回到待输入状态，已有文字保留。旧 Android 安装包可能没有麦克风授权代码，这时可用支持录音的浏览器，或安装包含该原生功能的客户端。

## 上传、核对与分组

1. 使用上传“＋”、拖放或粘贴添加图片，每批最多 4 张。单张最多 **20,000,000 字节**，解码像素最多 **7680 × 4320** 的总量。
2. 每张图片独立识别。点击图片打开核对窗口，左侧看原图，右侧看“文字信息”和“图形信息”。核对全部小问、公式、顶点、端点、箭头、重边、自环和权值；状态提示不等于数学正确性保证。
3. “原生识别”保留首次扫描的独立结果。需要重新选择局部时切换“自主框选”，选择文字或图形框选工具，框住所需内容。矩形和不规则框都可调整；不规则框可拖动局部边界，松手后重新识别该区域。
4. 自主框选中的“选择信息”分别管理文字框和图形框。新框识别后需要勾选才放入当前组合，可多选、拖动排序、删除。自主模式只组合所选框，不自动补入原生结果；随时可切回“原生识别”。选中的来源尚未完成、失败或为空时，先处理该来源再保存。
5. 点击“保存”校验并关闭核对窗口，不发送消息。核对后的图片卡片只显示“已核对”和“编辑”按钮；文字、图形和可选要求在“编辑”窗口查看或调整。未填写要求时不会自动附加“我的要求”。
6. 回到图片工作区，打开右上角“分组”。逐张选择是否为题目及组别；默认每张各一组。同一道题跨两张照片时放在同组，独立题保持分组。
7. 点击发送后立即回到聊天输入框，等待期间可点红色停止按钮。系统先核验所有图片及各组内容，再依组回答；未完成的图片在处理期间保留，停止或失败后重新显示。同组按上传顺序提交并共用一份回答；组内任一图片标记为题目，该组就按一道题记录，全组为“否”时不计入题目统计。图片组号与会话题号分别编号。

直接发送未保存的有效结果也会先执行同样的确认。识别未完成或确认失败时整批不会开始解题；停止、失败或切换会话会保留未完成图片，重试不会重发已完成的组。图片与识别草稿属于当前页面工作状态，不应依赖刷新恢复。

图形信息会展示图类型、顶点、位置、外观和边关系。无名顶点使用临时数字编号，编号只在当前子图内有效，不是原图的印刷标签；多图提问应写清“图片 2 的图 1 从 1 到 2”。边名和权值是不同内容，不应把同一个数字重复当作两者。外观与坐标仅供定位，不能用交叉画法推断连通或同构关系。

## 独立绘图

学习工具中的“绘图”打开独立画板。可新建或重命名页面，在“历史绘图”间切换；每个浏览器所属工作区最多保留 50 张。

绘图工具支持顶点、边、方向、权值、边名、曲线与自环，可选择对象修改属性、撤销 / 重做并调整布局。“适应”将实际图形居中；缩放不改变数学结构。“绘图设置”选择无向 / 有向、无权 / 带权，“图形信息”随编辑更新。

- **导出**：保存当前画板为 PNG；手机可显示图片预览，支持的 Android 客户端可存到相册。
- **AI 指导**：按当前画板和可选要求解释结构，不自动改图，也不把它登记为一道解题请求。
- **上传**：把当前绘制结构加入图片工作区，核对并发送后才进入对话。系统使用你绘制的结构，不重新猜测导出图片中的边。

绘图自动保存到当前浏览器的本地图库，按账号或游客分开，**不参与云同步**。游客绘图同样会在刷新后保留；清除网站存储会丢失本机图库，重要内容请导出。

## 错题、笔记与报告

**错题本**：从题目消息收录错题，保存解析和笔记，完成订正后发起同类复测；提交复测答案后记录通过、未通过或待进一步判断。支持搜索、筛选、排序、单题复制和 PDF 导出。当前错题容量为 240 条；复测尽量沿用原知识点与已存难度，生成题仍需核查。

**笔记本**：新建概念，填写名称与原文，输入时自动保存。打开或编辑概念不代表选中；勾选后可点“AI 解释”，选择至少两条可“分析关联”，并添加补充要求。AI 只读取本次所选笔记和补充要求，不读取其他笔记、旧聊天或错题，也不覆盖原文。修改、删除、换选或关闭会取消 / 忽略旧分析。

笔记常规容量为 100 条、合计 180,000 字符；每条名称最多 160、正文最多 6,000 字符。单次 AI 分析最多 12 条、名称与正文合计 24,000 字符。保存失败时保留当前页面并处理提示，关闭页面前不要假定已经云同步。

**学习报告**：在浏览器内汇总当前保留的题目、错题、概念和学习事件，不额外请求模型。同一对话内相同题干去重，同组多图按一题统计；报告提供待订正、待复测、概念笔记、知识追踪、题目来源筛选和返回原消息的入口。报告没有无依据的掌握度或能力分数，缺少时间的旧记录不会被编造日期。

**知识图谱**：目前含命题逻辑、谓词逻辑、证明与归纳、集合与关系、函数、初等数论、计数与组合、递推关系、图论、代数结构，共 68 个节点。可按当前题、会话或历史聚焦，查看相关节点及建议前置关系；这些关系用于学习安排，不等于严格逻辑蕴含。支持缩放、拖动和复制图谱 PNG，浏览器不允许写图片剪贴板时尝试下载。

## 账号与数据保存

未登录时，聊天、学习记录、错题、概念笔记和外观只属于当前页面，刷新或关闭后不保证保留；**独立绘图库是本机持久保存的例外**。

注册使用用户名、邮箱、密码和邮箱验证码；登录支持用户名或邮箱。注册成功返回一次恢复码，请妥善保存。账号面板还提供绑定 / 更换邮箱、邮箱或恢复码找回密码、修改恢复码、退出及输入当前密码永久注销。

登录后，会话、学习记录、错题、笔记和外观参数保存在本机缓存并同步到账号。多设备冲突自动合并并按修订号重试，必要时保留会话或笔记副本。退出前查看同步状态；未同步内容在退出清理学习缓存后可能无法找回。自定义背景图片和独立绘图库只在本设备保存，不能通过登录恢复到另一台设备。

## 外观、复制与设备差异

“外观”支持跟随系统、白色、黑色和蓝色，初始与恢复默认均为跟随系统；可调强调色、字号、壁纸、背景适配、遮罩、模糊、面板及聊天气泡透明度。登录后参数可同步，壁纸图片本体不上传。

公式使用 LaTeX 渲染。题目、错题和所选文字可复制；支持富文本的浏览器尝试保留格式与公式图像，否则回退为文本 / LaTeX。剪贴板、PDF、文件选择、相册和麦克风能力依赖设备及浏览器。客户端打开远程网页，网页更新不能替换已安装程序里的 Android / Tauri 原生代码。
