# 数据与隐私

本文说明源码中的数据去向和控制方式，不代表第三方服务的保留政策或线上运维配置。

## 阅读范围

“本机”指当前站点在当前浏览器 / WebView 的存储空间，浏览器、系统用户、站点域名或客户端变化后，通常是不同的存储空间。“云端”指部署者配置的账号数据库，不包括模型提供方、邮件服务、CDN 和运维备份。

游客不需要先登录，但识图、AI 与语音仍会按本次操作发送数据到服务端及相应提供方。“不云同步”只说明没有进入账号学习快照，不等于从未上传、从未被处理或第三方绝不保留。

## 本机与云端分别保存什么

| 数据 | 游客 | 登录账号 |
| --- | --- | --- |
| 对话、题目历史、错题、概念笔记、学习事件 | 当前页面内存；刷新 / 关闭不保证保留 | 本机学习缓存，并同步到 PostgreSQL |
| 外观参数 | 当前页面 | 本机账号缓存与云同步 |
| 自定义背景图片 | 页面内 Blob | 当前设备 IndexedDB，图片本体不云同步 |
| 独立绘图库 | 当前页面内存；同页重开绘图可继续，刷新 / 关闭网页后清空 | 按账号区分的本机 localStorage，不云同步 |
| 尚未发送的图片与框选草稿 | 当前页面任务 | 同样属于当前页面任务，不作为完整草稿库云同步 |

登录后的云快照包含 `sessions`、`learning` 和 `appearance`，笔记属于 `learning.conceptNotebook`。主要学习缓存键以 `discrete_math_ai_` 开头；账号独立图库使用 `dmate:graph-gallery:v1::` 前缀，按 `account:<用户名>` 分开。游客绘图不写入 localStorage 或 sessionStorage，旧版游客图库与无归属 / 游客旧画板持久数据会清理，不导入新的游客工作区。命名分区不是加密，也不能防止拥有当前浏览器存储访问权的人读取数据。

云同步使用修订号检测冲突；前端合并后重试，必要时保留冲突副本。服务端拒绝 `force=true`。12 MiB 同步上限或本机容量不足可能阻止保存，发生错误时应保留页面并导出重要资料，不能假定后台已经成功同步。

### 同步与本机保存的实际含义

自动保存到页面、本机缓存和账号数据库是不同步骤。笔记已出现在界面、画板已完成编辑，都不能单独证明账号快照已同步。网络中断、身份过期、版本冲突和容量不足均可能阻止云端更新。

登录账号的独立画板按账号名称分区存储，这用于避免正常切换账号时互相展示，不属于存储加密或操作系统用户隔离。游客画板只在当前页面会话内保留，关闭并重开绘图弹窗不会清空，刷新或关闭网页才结束这份临时工作区。浏览器无痕窗口、不同浏览器、Android WebView 与桌面 WebView 也不应被视为同一个图库。迁移设备或离开游客页面前，可导出重要画板和错题资料；PNG、PDF 等导出文件不会自动成为另一设备上的可编辑图库或完整账号备份。

## 服务端存储

- `dm_users`：账号标识、验证邮箱、密码哈希、恢复码哈希和认证版本。
- `dm_user_data`：账号学习快照 JSONB、修订号和更新时间。
- `dm_email_codes`：验证码摘要、用途、过期与消费状态、错误次数。
- 图形确认 SQLite：浏览器 / 账号关联摘要、请求 ID、原图摘要、文档摘要、令牌摘要、修订号与过期时间。这里保存确认登记，不保存原图或整份题目正文；有效期为 7 天，后续访问时清理过期登记。

本地文字识别可能使用临时文件和模型缓存；语音适配器在内存中处理 WAV，不把录音写成聊天附件或业务历史。运行日志、代理日志、数据库备份和第三方保留情况由部署者及对应服务决定。

## 发送给哪些第三方

| 操作 | 发送内容 / 服务 |
| --- | --- |
| 教学、出题、答案诊断 | 当前请求、必要历史及题目 / 已确认图结构，发送 DeepSeek |
| 错题旧记录分类补全 | 打开错题本时，缺少或过时的分类与难度可能触发后台补全，将相关题干发送 DeepSeek |
| 网页自动识图、图形局部重识别 | 原图或所选图形区域及必要结构上下文，发送 DashScope / Qwen |
| 文字框识别 | 图片区域在服务端本地 PaddleOCR CPU worker 处理 |
| 笔记 AI 解释 / 关联 | 仅本次选择的概念原文和补充问题，发送 DeepSeek |
| 绘图 AI 指导 | 当前绘图结构及本次要求，发送 DeepSeek，不自动改图 |
| 语音转写 | WAV 音频及模型 / 词库参数，发送 DashScope |
| 邮箱验证 | 收件地址、验证码和邮件内容，发送 Brevo 或 SMTP 服务 |

服务端还保留显式兼容识别路径，可能按配置调用 Qwen 或 GLM；当前网页自动识图不使用 GLM，也不在失败时自动换提供商。识别与解题为不同请求，图片的用户确认不等于自动证明结构与原图一致。

学习回顾和知识图谱展示在浏览器内整理已有数据，打开它们不产生额外模型调用。学习回顾只按本地规则生成“最近学习”“值得再看看”“接下来可以做”三段概要，不另存一份评分或档案数据。公式、Markdown、内容清洗及 PDF 库从 jsDelivr 加载，浏览器会与该 CDN 建立连接。

### 图片操作各阶段发送什么

自动扫描发送原图用于读取；框选文字时，服务端对所选像素运行本地 OCR；框选图形时，相应区域及必要上下文进入视觉识别。保存核对结果调用确认校验，不额外请求模型。发送解题时提交已确认的题干和结构及使用者实际填写的要求，按教学请求发送到文本服务。

原图来源与确认登记仅保存摘要及身份元数据，并不是服务器上的照片相册。完整语义快照由前端保留并在解题时提交；用于聊天和同步的题目正文属于学习内容，不能因为原图登记不保存全文，就认为题干也从未进入聊天或云快照。

笔记和绘图指导的“只发送所选 / 当前内容”是这些专用接口的范围，不表示普通聊天永远不携带历史。普通聊天会带必要的近期历史；如果不希望某段内容参与后续问答，应明确管理会话与输入内容。

## 账号、密码与 Cookie

密码和恢复码使用 scrypt 哈希。自动恢复码只在注册响应中返回一次明文；邮箱验证码以 `AUTH_SECRET_KEY` 参与 HMAC-SHA256 摘要保存。

验证码为 6 位、10 分钟有效，同用途重发间隔 60 秒、同邮箱同用途每小时最多 8 次，单个验证码最多 6 次错误尝试。邮箱重置发送接口对不存在的邮箱仍返回统一成功外观，降低直接枚举风险。密码重置提高 `auth_version`，使其他旧登录 Session 失效。

认证使用 Flask 签名 Cookie `dm_tutor_session`，默认 HttpOnly、SameSite=Lax、Secure、30 天滚动有效期。签名防篡改，不等于加密 Cookie 内容；前端不保存可复用登录 token。生产保持 HTTPS 和稳定的 `AUTH_SECRET_KEY`，仅本地 HTTP 调试可关闭安全 Cookie。

图片确认另有 HttpOnly、SameSite=Lax 的浏览器归属 Cookie，并结合已签名账号 ID 隔离任务；它不是账号登录凭证。

更换浏览器、清除 Cookie、切换账号或让登记到期后，旧确认快照可能不能继续使用。应从当前图片重新建立确认，不把确认令牌当作可跨账号、跨设备使用的通用访问密钥。确认有效期与登录 Cookie 的有效期也不同。

## 请求限制与内容显示

聊天默认每身份每分钟 20 次；图片、语音、笔记分析和绘图指导各自默认每分钟 10 次。普通功能优先以已登录账号计额，游客按来源地址；账号路由另用每路由 / IP 每分钟 20 次限制。限流和部分并发额度存于单进程内，增加实例需重新设计共享限制。

只在直接连接的代理属于 `TRUSTED_PROXY_CIDRS` 时解析转发链，避免客户端随意选择限流地址。配置不当会把多位用户归为一个地址，或把不可信地址当作代理。

AI 富文本通过 Marked 解析、DOMPurify 清洗后显示，再交给 MathJax 渲染公式；图标签和只读描述使用文本节点。服务端 API Key、数据库及邮件凭据仅从运行环境读取，不应打包到客户端或提交到仓库。

输入校验、结构 Schema 和受限数学工具用于缩小无效请求与不可信输出的影响，不是识别结果或数学答案的准确性认证。上游服务返回的文本仍需作为模型输出理解，尤其在题干缺失、图结构不完整或证明题条件复杂时。

应用停止按钮会中止前端等待，并在支持的识别阶段登记取消。已经发往提供方的请求可能继续执行；取消不能作为撤回数据、删除提供方记录或免除已发生费用的证明。

## 退出、删除与本机副本

退出只结束当前浏览器登录，保留账号与云端数据；前端清空学习缓存并返回游客工作区，未同步内容可能丢失。永久注销需要当前密码，删除账号及关联的云端学习数据和已关联验证码。

这些操作不能远程清除其他设备、导出文件、备份、服务日志或第三方副本；账号独立绘图库等本机数据也不能仅靠账号删除接口清理。共享设备上，完成同步或导出后可用浏览器网站数据管理清除对应站点存储，这会同时删除本机账号图库和壁纸。游客图库不持久保存，刷新或关闭网页后清空。知识图谱不保存掌握度，学习回顾不展示能力百分比或其他数字指标。

| 操作 | 直接影响 | 不等同于 |
| --- | --- | --- |
| 删除对话 | 删除该对话及其学习统计；已加入错题本的题目保留 | 删除全部错题、笔记或其他设备的离线副本 |
| 删除错题 / 笔记 | 从当前学习数据移除相应条目，登录后随成功同步更新云快照 | 立即抹除历史备份和所有导出文件 |
| 删除历史绘图 | 删除当前账号本机图库或当前页面游客工作区中的画板 | 删除其他设备的图库或先前导出的 PNG |
| 退出登录 | 结束当前登录、清理前端学习缓存并返回游客状态 | 注销账号或远程退出所有设备 |
| 永久注销 | 校验当前密码后删除账号及关联云端数据 | 清除所有本机文件、备份或第三方记录 |
| 清除网站数据 | 删除此浏览器对应站点的 Cookie、缓存和本机存储 | 调用账号注销或删除数据库中的账号 |

## 部署者需要另行说明的内容

线上服务的数据处理主体、运维日志保留期、数据库备份周期、模型供应商的具体地域及保留策略、邮件投递记录和适用条款，不能只由仓库代码确定。自托管或对外提供服务时，应按真实配置补充这些信息。维护时不应把 Key、Cookie、确认令牌、录音或完整题目写入公开排障记录。

运行配置与备份边界见[部署说明](DEPLOYMENT.md)，各请求字段与限制见 [API](API.md)。
