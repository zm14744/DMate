# DMate Offline（实验性本地版）

这是 DMate 的**独立本地工作台**，与线上版并存，**不会替换现有 Tauri 桌面客户端**。第一版提供本机 AI 聊天、图片提问（需要本地视觉模型）、错题本、笔记、基础图论计算，以及 JSON 数据备份与恢复。

所有网页、API、SQLite 数据都在本机。程序只监听 127.0.0.1，除连接本机 127.0.0.1:11434 的 Ollama 外不发起网络请求。离线使用前须先联网安装软件、下载模型；之后无需腾讯云、Zeabur、DeepSeek 或 DashScope API Key。

## 安装与启动

要求：**Python 3.10+** 和 [Ollama](https://ollama.com/download)（Mac、Windows、Linux 均可）。

联网状态下，在终端运行：

~~~sh
ollama pull qwen3:4b-thinking-2507-q4_K_M
~~~

该文本模型下载量约 **2.5GB**。它是专门的 Thinking 版本，更适合数学推理和证明任务。如果要识别题目图片，可额外下载：

~~~sh
ollama pull qwen3-vl:4b
~~~

它的模型文件约 **3.3GB**。两款模型不会随此仓库提供，务必确认本机有足够存储空间与内存。建议先从 4B 量化模型开始。更大的模型不一定适合没有独立 GPU 的电脑。

启动 Ollama 应用；Linux 如未自动启动，则运行 ollama serve。然后在 **仓库根目录**执行：

macOS / Linux：

~~~bash
python3 offline/dmate_offline.py
~~~

Windows（PowerShell 或 CMD）：

~~~bat
py -3 offline\dmate_offline.py
~~~

浏览器会自动打开 http://127.0.0.1:8765。可以通过 --no-browser 禁止自动打开浏览器，通过 --port 8766 修改工作台端口。

**使用图像提问时，请手动切换到本地视觉模型 qwen3-vl:4b。** 不支持视觉输入的纯文本模型无法可靠处理图片。

## 能做什么

- **离线 AI 对话**：从已安装的 Ollama 本地模型中选择，支持流式回复、历史对话保存。
- **离线图片提问**：图片在本机送给 Ollama 视觉模型；不保存原图，历史中只保留提问文本和图片标记。
- **错题本、笔记**：存入本机 SQLite；无需注册和云端同步。
- **图论工具**：简单有向 / 无向图的度、邻接矩阵、连通分量及 BFS；无向图还可判断是否为树。
- **备份与恢复**：将对话、笔记、错题导出为 JSON。导入时会明确询问是否替换所有现有离线数据。

用户数据默认存放在 ~/.dmate-offline/dmate.sqlite3，可在启动之前设置 DMATE_OFFLINE_HOME 指定位置。**备份 JSON 不加密**，请自行妥善保存。关闭程序和断网不会删除数据。

## 现阶段不支持

本版本是可以运行的 **MVP，而非在线 DMate 的功能完整移植**：

- 不复刻原网页全部界面、绘图工作区、自动图形提取、智能体编排与错题自动复测。
- 不包含 PaddleOCR / PaddleX 的原生本地图片识别管线；图片交给选择的本地视觉模型分析，准确率有差异。
- 没有账号、跨设备云同步、语音转写、远程模型、邮件注册。
- 暂无独立的已签名 Tauri 安装包；当前需要 Python 启动本机网页工作台。
- 数学文本初步支持原始 LaTeX 语法；排版效果不保证与在线版完全相同。
- 不能把本项目直接放在 2 核 4GB 的云服务器上就称为本机离线 AI。模型运行于**使用者自己的电脑**，需要足够内存与存储。

## 安全约束

服务端只绑定 127.0.0.1；拒绝非本机 Host 与跨源 Origin；写入操作要求本次启动随机产生的本地请求令牌；未添加任何 CDN、埋点、远程兜底或自动下载模型的逻辑。应用的模型列表来自本机 Ollama，明确过滤云模型名称。所有数据库写入使用参数化 SQL。

该设计降低了网络风险，但不能替代操作系统账户保护、磁盘加密或外部备份。Ollama 是单独安装的软件；请使用本地模型，不要在 Ollama 中选择云端模型。

## 测试

不需要 Ollama，也不需要网络：

~~~bash
python3 -m compileall -q offline
python3 -m unittest discover -s offline -p 'test_*.py' -v
~~~

测试通过本机模拟 Ollama 验证流式回复、会话持久化、备份的事务回滚、图论算法与跨源保护。首次实际运行时仍需要在目标电脑验证模型版本、性能和视觉准确率。

本地 Ollama API 规范：<https://docs.ollama.com/api>。本项目没有额外的 Python pip 依赖。
