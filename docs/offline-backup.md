# 学习资料 ZIP 备份

在线版的“导出数据”和离线版的“导出数据”生成相同格式的 `DMate-日期.zip`；离线版通过“导入数据”选择整个 ZIP 包恢复，无需解压。离线版不需要联网即可导出和导入，安卓版通过系统文件选择器保存和选择 ZIP。

备份包含笔记本中的概念名称及内容、错题的题目／答案／解析及关联信息，以及保留顶点、连线、权重、标签和页面设置的可编辑绘图库。二进制附件单独存放在 `attachments/`。内置概念库、练习库、对话、外观、账号凭据和设备加密密钥不在备份范围内。

离线资料保存在当前设备的加密资料库，无需登录；登录、退出、断网或关闭后重新打开均不切换或清空资料。同一存储空间的新标签页共享资料，不同设备、浏览器及客户端存储空间分别独立。进入离线版直接读取本机内容，在线资料通过用户选择 ZIP 明确导入。

导出前等待当前概念和绘图保存完成。导入先检查全部文件、版本、结构和 SHA-256，再向设备资料库追加内容，本机原有记录保持不变。去重按实际内容进行，ID 和记录时间不同仍可合并：概念比较名称、正文及实际附件；错题比较题目、答案、解析及实际附件；绘图比较名称、要求、正文、顶点、连线、标签和权重等可编辑内容，忽略页面及图内生成 ID、视图缩放和平移及派生描述。同一个 ZIP 内的相同内容也只新增一次，不同内容分别保留。

错题导出不包含创建、修改、订正等跟踪时间；导入新增错题时生成本机时间，相同错题合并时保留本地原时间。旧版含时间的 ZIP 仍可读取，时间不参与内容去重。包清单的备份创建时间用于识别备份，不参与记录去重。

大备份按存储批次写入，中断后会说明已恢复数量，可以重试，避免重复恢复。绘图库合并后仍遵循编辑器的 50 幅图上限。

ZIP 内含 `manifest.json`、`notes.json`、`mistakes.json`、`drawings.json` 和按需添加的附件。清单格式为 `dmate-offline-backup`、版本为 `1`，记录文件大小、SHA-256 和资料数量。包内资料可直接读取，便于跨设备迁移。

安卓版需要包含 `DMateFileSave` 文件保存接口和通用文件选择器的新客户端。旧客户端不会错误显示已导出，而是提示更新客户端及系统 WebView。
