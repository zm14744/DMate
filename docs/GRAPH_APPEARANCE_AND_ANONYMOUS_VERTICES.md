# 图形外观与无名顶点引用

2026-10-29

图片核对窗口的右栏现在分别显示每幅图的外观、顶点位置和边关系。原有上传界面和左侧原图保持原样，右栏仍然只读，不生成新的图形预览。

## 识别和数据流

- Qwen 在原有主识别调用中同时返回 `visual_description` 和各顶点的 `position_description`。描述说明原图左右位置、外圈/内圈、上下排、直线、弧线和交叉画法；同构题中的两幅图分别描述，不根据题意补造连接。不增加描述专用模型调用。
- 无名顶点保留 `label:null`；程序单独分配 `display_label`，如①、②。编号按顶点 ID 补全，已有有效编号保持不变，并避开原标签和重复编号。说明会明确编号不是原图文字，而且只在当前子图内有效。
- 位置优先使用原图视觉描述，缺失时仅根据已记录坐标提供粗略相对方位。不根据坐标猜测顶点、边或数学性质；未获得的具体曲线形态明确说明未提供。
- 描述、位置和编号通过规范化、确认摘要、浏览器存储、聊天请求及解题结构全程保留。坐标和路径仍留在绘图数据，不进入数学快照。
- 解题提示明确区分外观参考和已确认端点关系。两幅图都有①，不代表它们是同一个顶点，也不代表存在①到①的同构映射。

## 同构和路径计算

`graph.semantic_math` 增加显式双图操作：

```json
{"operation":"isomorphism","graph_id":"G1","other_graph_id":"G2"}
```

NetworkX VF2 比较实际边实例，保留方向、自环、重边和孤立点，忽略标签、编号和布局。成功时返回带左右图 ID 的顶点 ID 映射。工具不修改输入，也不因外观或图名推断答案。

该工具仅处理完整、明确方向的无权图，限制为每图32个顶点、128条边、50,000个搜索候选、2秒协作式搜索上限。带权、未知或混合方向、未确认结构、超限或未完成搜索均返回 `not_applicable`，不能当作不同构。没有明确指定两个图且图片包含三幅以上图时，不自动选择比较对象。

路径请求可以引用临时编号。多图中，明确写“图1从①到②”只计算图1；未指定图且多个图均含这两个编号时，不擅自计算。

## 验证

- `test_graph_presentation.py` 覆盖规范化、碰撞、重排、实际确认→浏览器清洗→聊天签名链路、字段上限和跨图引用。
- `test_graph_appearance_ui.py` 在桌面、手机浏览器验证只读描述、位置说明、编号及实际提交内容；原上传和扫描交互测试继续执行。
- `test_semantic_isomorphism.py` 覆盖不同画法、无名顶点、同度数但不同构、方向、自环、重边、孤立点、不适用情况和搜索上限。
- 实际调用用户提供的 `oct21_030` 无名双图与 `oct21_031` 双图图片，分别获得外观与位置描述。模型未确定的连线继续保留待核对状态。这些测试用于验证描述与引用链路，不代表整个图片集已达到零错误。
- 收紧外观提示后再测 `oct21_030`：服务端完整流程51.031秒，两幅图分别4点6边，8个顶点均为 `label:null` 且有临时编号与位置，左右图分别描述水平/竖直连线差别，本次返回 `complete`、无警告。该耗时不含网络上传和浏览器绘制。
