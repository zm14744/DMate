# DMate 知识图谱说明

当前 `knowledge_graph.json` 包含 **10 个模块、68 个知识节点**。图谱用于教学提示、建议前置知识提醒和学习状态关联；`prerequisites` 表示建议学习前置/依赖关系，不等同于严格数学逻辑蕴含。图谱不记录学生掌握度。

## 权威依据

- 高等教育出版社《离散数学（第3版）》：https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=658daaba74ce561611bd9a4f
- MIT OpenCourseWare — Mathematics for Computer Science：https://ocw.mit.edu/courses/6-1200j-mathematics-for-computer-science-spring-2024/
- Kenneth H. Rosen — *Discrete Mathematics and Its Applications*：https://www.mheducation.com/highered/product/discrete-mathematics-and-its-applications-rosen.html

## 教学分类连接

`teaching.py` 的课程分类名称与图谱模块一致：命题逻辑、谓词逻辑、证明与归纳、集合与关系、函数、初等数论、计数与组合、递推关系、图论、代数结构。分类结果用于生成 `knowledge_points`、`prerequisite_points` 与 `knowledge_path`。

## 2026-10-08 新增知识点与边界

相较旧版 64 节点，本版新增 **4 个节点**：初等数论的“模逆与中国剩余定理”，以及图论的“图同构”“二部图”“拓扑排序”。节点与建议前置关系均直接来源于当前 `knowledge_graph.json`，不手工另建平行数据。

`teaching.py` 对自然语言题干的分类覆盖了上述节点，并强化了公式型线性齐次 / 非齐次递推的识别。题型和难度均为规则判断，误识别仍有可能；知识图谱只提供学习组织关系，不承诺完全、穷尽地覆盖每一种离散数学题型。
