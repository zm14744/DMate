# DMate 离线模式设计

## 1. 产品决定

采用**一个 DMate、两种工作状态**，不再维护一个功能重复的独立离线聊天产品。

- 在线状态：保留现有完整 DMate。
- 离线状态：进入本地学习工作区，提供无需云端服务的六个模块。
- 在线与离线共用知识点编号、内容包格式和个人学习数据模型。
- 离线模式不要求安装本地大语言模型，也不把 OCR、语音或云端 AI 伪装成离线功能。

### 离线工作区范围

1. 知识图谱：在主内容区按模块浏览，查看前后置知识，支持缩放、完整查看和图片导出。
2. 概念库：按知识点浏览定义、解释、公式、例题、易错点及关联知识，完整支持简体中文和英文。
3. 练习库：按章节和简单／中等／困难筛选，阅读双语题目、只读选项和参考答案解析，不提供加入错题本、作答或评分入口。选项只展示字母与正文，没有逐项卡片边框或底色。旧内容的基础／进阶分别映射为简单／困难。
4. 绘图：复用在线版的绘图界面及本机图库，支持创建、编辑、保存和导出；离线界面不提供 AI 指导或上传。
5. 错题本：查看本机保存或从 ZIP 导入的错题及答案，支持移出错题本；不显示订正状态、解析或手动添加、编辑入口，原有记录字段仍保留。
6. 笔记本：创建、编辑、选择和删除概念笔记，沿用原页面的功能与当前在线版按钮样式；不提供在线 AI 分析。

离线工作区按设备的浏览器／WebView 存储空间长期保存资料，无需登录。登录、退出、联网与断网均不切换或清空本机内容；关闭后重新打开及同一存储空间的新标签页可继续使用。不同设备、浏览器和客户端存储空间分别独立，页面选择等视图状态按标签页保存。进入离线版直接打开本机资料，不再自动接收当前在线账号的快照；用户可通过 ZIP 明确导入概念笔记、错题及答案和可编辑绘图。

不纳入本阶段：在线聊天生成、云端视觉识别、语音转写、邮件登录、实时课程视频、AI 自动出题和 AI 自动解析。

## 2. 网页入口与自动离线进入

### 在线时

在 DMate 现有导航中增加一个明确的 **“离线版”** 入口。

点击后：
1. 直接打开 `/offline`，读取当前设备的本机资料，不等待账号、在线快照或云端接口。
2. 检查离线应用外壳、知识图谱、题库和概念库是否已缓存。
3. 后台缓存离线资源；自动播放开场动画，原页面恢复就绪后进入工作区。
4. 缓存完成后，可以断网继续使用。
5. 离线工作区提供“返回在线版”入口。

### 断网时

通过 Service Worker 接管 DMate 站点的导航请求：
1. 正常联网时优先访问网络。
2. 网络请求失败或超时后，返回已缓存的离线应用外壳。
3. 离线工作区只读取本地资源与本地数据库，不等待云端 API。
4. 网络恢复后可返回在线版；不强制刷新页面、不打断用户当前操作，也不把本机记录误报为已同步到云端。

实现上使用 Service Worker、Cache Storage 和 IndexedDB。Service Worker 缓存应用外壳和静态资源；IndexedDB 保存独立于账号的本机学习记录。不能只缓存一张离线提示页，否则题库、概念库和编辑功能仍然无法使用。

### 必须明确的首次使用限制

浏览器无法在用户从未访问过 DMate、从未安装或缓存离线资源、且当前完全断网的情况下，凭空打开 DMate 页面。

因此，用户至少需要在有网络时访问一次 DMate，并完成离线资源准备。之后才能在断网时自动进入离线工作区。若用户清除网站数据、换浏览器或使用新设备，也需要重新准备一次。

浏览器的“无网络”判断不能只依赖 `navigator.onLine`；它只是提示信号。真正的降级应以导航请求失败、Service Worker 缓存命中和 API 请求失败为依据。

## 3. 本地数据与同步

### 本地存储

- IndexedDB：`dmate-offline-vault-v1` 中的 `device-workspace-v1` 保存加密的错题、笔记、历史练习、设置、外观背景和绘图库；当前练习界面不创建新作答记录。`offline-storage.js` 以 `scope:"device"` 统一适配业务读写、revision 冲突和原子删除墓碑。
- Cache Storage：离线 HTML、CSS、JavaScript、MathJax、本地知识图谱、题库和概念库资源包。
- Web Storage：不再写入新的离线绘图库、外观或学习正文副本；只保留视图会话及旧迁移兼容所需的控制数据。题库与概念库正文由版本化资源包提供。
- 已登录和未登录时使用同一设备 vault；刷新、关闭页面或应用后重新打开，已提交资料继续保留。登录退出和在线游客会话结束不会清理离线资料，也不自动跨设备同步。
- 旧 `dmate-offline-workspace` 升级到版本 4。旧本机账号／游客 vault 合并到设备库，原密文来源保留；迁移日志按来源和记录 revision 避免重复恢复及已删除内容复活。旧明文离线来源先加密提交后处理，失败保留源供重试。

新版 Android/Desktop 的设备 vault 使用系统密钥；普通浏览器使用不可导出的 Web Crypto 密钥。旧版已暂存在本机的短期加密交接包仅作兼容迁移；新入口不再创建交接包。缺少原生桥的旧客户端需要更新，保存失败不会降级到其他密钥提供者。完整边界、API 和测试限制见 [离线保密存储与平台边界](OFFLINE_CONFIDENTIALITY.md)。

笔记输入不显示“已保存”提示。绘图库使用异步保存，导出、确认及返回在线版等待提交，失败保留当前编辑供重试。不能把“已显示在页面”误报为“已同步到云端”。

### 与现有云同步的关系

现有账号同步使用 PostgreSQL、revision 比较和冲突合并，可以作为在线恢复后的同步基础，但不能直接假设所有离线数据都已经纳入同步：

- 在线错题、概念笔记和账号学习快照维持原同步路径；进入离线版不会自动复制这些内容，也不会替换在线数据。
- 在线独立绘图库执行现有本机及会话规则；离线绘图库保存在设备 vault。两者可通过用户明确选择的 ZIP 备份转移。
- 离线绘图、错题和笔记无需登录即可长期保存；在线游客对话及在线资料原有的会话规则保持不变。
- 知识图谱、题库和概念库是应用资源，不是个人学习记录；采用版本化资源包更新，不放入个人同步快照。

本机修改不会自动提交到云端。ZIP 导入采用追加与按内容合并：名称和内容相同的概念、题目／答案／解析相同的错题、可编辑内容相同的绘图直接融合，忽略 ID、时间和绘图视图等记录信息；不同内容新增，本地原记录保持不变。错题导出不含记录时间，新增错题导入后使用本机时间，旧 ZIP 仍可读取。详见 [学习资料 ZIP 备份](offline-backup.md)。

## 4. 内容包设计

- 题库和概念库采用版本化 JSON 数据包，附带内容清单、校验摘要和来源许可清单。
- 内容记录关联现有 `knowledge_graph.json` 节点编号。
- 用户界面全部使用简体中文；内部编号和数学公式不展示为英文说明。
- 题库与概念库可独立更新，不要求重新安装整个 DMate。
- 不将 CC BY、CC BY-SA 和 DMate 自有内容混成一个无法区分许可的包。

首批内容预览见 `offline-content/`。

## 视觉一致性要求

离线工作区不是第二套品牌视觉，不创建独立的配色、字体、Logo 或图标体系：

- 直接复用主站的 DMate 品牌 SVG、原有图标路径和图标线条规格。
- 复用从主站样式中提取的原始主题 CSS，沿用白色、黑色、蓝色主题及现有 CSS 变量。
- 离线主题、主题色、字体大小、面板透明度、气泡透明度、背景适配、遮罩和模糊设置保存在当前设备工作区。
- 自定义背景图保存到离线工作区的加密设置记录；旧本机外观来源仅作兼容迁移，登录切换不替换离线设置。
- 离线工作区只增加必要的布局和内容样式，不重绘原有 Logo、图标或背景。

在线和离线页面直接引用公共样式 `static/dmate-main.css`。调整在线模板中的内联覆盖样式后，
运行 `python scripts/sync_offline_styles.py` 更新 `static/dmate-shared-overrides.css`。CI 使用 `--check`
检查两端是否一致。离线布局保留在 `offline.css`，按钮、绘图、弹窗、
公式排版及图标复用在线组件。知识图谱以同样的节点、连线和选中描边显示，
离线题库与概念库沿用相同的列表和详情样式。

概念、题干、选项、参考答案和解析使用 `math-markdown.js` 的共享格式化实现，配合 `DMateAIAnswer` 的聊天正文模式，复用在线 AI 的字体、Markdown 和 MathJax 排版。英文译文按原始条目编号查找，不修改知识点、题目、答案键及旧学习记录。切换语言时保留当前选择、筛选、搜索和参考答案展开状态；语言偏好保存在离线设置，完整英文内容预缓存后可在断网状态使用。

上述样式、脚本及本地 Markdown / MathJax 资源均纳入离线缓存；新增依赖时
同步更新 `offline-service-worker.js` 的资源清单和缓存版本，避免断网后缺少图标、
弹窗或公式。浏览器回归需要完成在线准备，再断网刷新并检查各模块和本机记录。

## 5. 对现有代码的影响

当前架构有以下约束：

1. 现有 Tauri 桌面壳的 `frontendDist` 和窗口地址指向远程站点；它不是完整的本地离线应用。
2. 现有模板包含清理旧 Service Worker 和历史缓存的逻辑。引入正式离线缓存时，必须只退役旧版缓存，不能把新离线 Service Worker 一并注销。
3. 离线绘图、错题、笔记及历史练习记录通过加密适配器保存到设备库；旧本机资料按迁移日志合并，新增外部资料通过用户选择 ZIP 导入。
4. 在线独立绘图库保留原有规则；离线设备图库长期保存，不属于账号云同步快照。
5. 现有知识图谱已经随仓库提供，可作为本地资源基础；其节点编号应继续作为题库和概念库的统一知识点标识。

当前已接入离线工作区路由、缓存、内容包和加密持久化；自动云同步与桌面静态资源随包分发仍属于独立后续工作。

## 6. 推荐实施顺序

以下保留阶段划分作为后续维护路线。工作区、离线缓存、内容包及加密业务存储已接入；第四阶段的扩展同步和第五阶段的资源随安装包分发不代表本次已经交付。

### 第一阶段：本地持久化
- 已提交的离线绘图、已有练习记录和必要学习状态在刷新、关闭后保留，无需登录。
- 登录前后使用同一设备资料库，每台设备独立保存，各标签页独立保存视图。
- 验证现有绘图导出及历史练习记录不受只读浏览影响。

### 第二阶段：离线工作区
- 增加“离线版”入口和 `/offline` 页面。
- 将六个模块接入本地资源与保存层。
- 保留必要的离线状态和保存错误反馈，输入时不增加“已保存”提示。

### 第三阶段：自动离线进入
- 注册并维护正式 Service Worker。
- 预缓存应用外壳、静态资源、知识图谱和内容包。
- 网络失败时自动回退到离线工作区。
- 验证首次访问、断网、恢复网络、更新缓存和清除站点数据等场景。

### 第四阶段：内容与同步
- 导入经审核的中文题库和概念库。
- 版本化资源包。
- 扩展绘图等数据的账号同步。
- 验证多设备同时编辑和删除冲突。

### 第五阶段：桌面端
- 将离线工作区及必要静态资源随 Tauri 安装包打包。
- 桌面端离线启动不再依赖远程首页。
- 在线站点更新与桌面端安装包更新分别管理。

## 7. 验收标准

- 完成一次在线准备后，断网并重新打开 DMate，能自动进入离线工作区。
- 断网时六个模块可用；不触发云端 AI、OCR、语音或登录请求。
- 已提交的离线绘图和已有练习记录在刷新、重启浏览器或应用后仍然保留，无需登录；登录、退出及断网不清空或切换资料。题目浏览不新增或改写练习记录，未完成的异步提交不能视为已保存。
- 离线错题支持从 ZIP 导入、查看答案和移出，笔记支持新增、编辑、删除；设备持久化、跨标签页共享、按内容去重及旧资料迁移正确。相同内容不额外增加，不同内容追加并保留本地原记录。
- 恢复网络后可以返回在线版；当前本机副本不自动上传，今后扩展同步时不得静默覆盖冲突。
- 清除缓存、首次访问和新设备场景有清楚提示，不承诺“从未准备也能离线打开”。
- 内容包的版本、中文质量、来源和许可证可以逐条追溯。
