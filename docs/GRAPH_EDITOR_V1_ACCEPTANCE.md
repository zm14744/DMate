# DMate 原图描绘 V1：冻结验收标准与进度

更新：2026-10-27。适用开发分支 `codex/graph-editor-cleanup-20261027-a` / PR #27。**这是执行标准，不是声称已经完成。** 部署线上或合并到 main 前必须逐项给出结果。只运行自动测试或提交代码，不算完成图片识别验收。

## 0. 与现有指标的关系

AI 自动识别仍按照仓库已冻结的 [core-recognition-acceptance.md](core-recognition-acceptance.md)：
**11 张常见清晰图、20 个子图、104 个顶点、131 条边、27 条清晰有向边、19 个权值**；分图数、点数、边数与基础图类型要求 100%，连接/方向/权值 ≥90%，点标签 ≥95%，单图整体目标 ≤120 秒（前提为所选工具都真实完成）。不改参考图片、不改变分母、不将人工纠正计作 AI 自动识别成功。阴影透印 `photos_004` 仍属于独立诊断样本。

V1 优先交付 **AI 生成可编辑初稿 + 原图 SVG 描绘 + 人工核对 + 确认后数学结构**。下表的 100% 均指确定性软件行为，并非原图 AI 识别率。

| E02 | 顶点录入与保存 | 添加、拖动、更名、删除；在原图 100%、200%、400% 缩放下反算归一化坐标误差 ≤0.005；同一顶点保存后重开坐标误差 ≤0.000001 | 已编码，未完成多倍率验收 |
| E03 | 连边 | 直接选两端生成一条独立边；端点 ID 100% 正确，不以画面交叉点自动创建顶点或边 | 已编码，浏览器用例待验收 |
| E04 | 重边与自环 | 1~3 条重边和自环分别保存独立 edge.id，端点/方向/权值/路径不串线；删单条不误删另一条 | 数据模型已有，SVG 复杂用例待验收 |

| E06 | 无名点、无名边 | 原图无名顶点的 label 始终为 null；①②③ 等临时名在删除其他顶点、撤销、确认后重开保持不变；无名边不生成可见名称 | 已编码，待整套回归 |

几何误差仅比较**用户明确放置/校准后的位置与保存结果**，不是要求 Qwen 在所有复杂照片中精确找点。

## 2. 渲染、描述与解题硬指标

| 编号 | 标准 | 当前状态 |
| --- | --- | --- |
| R01 | 每图字段固定依次为「点、边（有实际边名才显示）、关系、图形描述（有则显示）」。图名旁标方向和权值；不额外显示随机 e1/e2 假边名 | 基础格式模块已编码 |
| R02 | 关系表 **一行一条实际边**；无向「A—B」、有向「A→B」、权值「（权值：0）」；重边不得因端点相同合并；未知方向必须显示待核对 | 基础格式模块已编码，原结果展示仍要端到端核查 |
| R03 | ①②③ 与原图对应点 ID 一致；点/边关系点击定位同一对象。图形预览和最终结果不可使用互相矛盾的编号 | 基础双向定位部分接入，最终联动待测 |
| R04 | DeepSeek 只读取**已确认**的绘图摘要生成 ≤90 汉字目标的布局描述，不根据名称判断同构、欧拉、哈密顿或直接解题；描述失败/跳过**不阻止**结构确认与解题 | 接口已编码，受限输出测试未全部通过前不算通过 |
| R05 | 用户确认后实际送给解题模块的 document SHA256 与确认记录一致；改一个端点/方向/权值/题干都必须触发重新确认 | 原有安全机制已实现，新兼容回归待验收 |

## 3. 测试门槛与退出条件

- **工程门槛 A：** PR 当前 HEAD 的完整 Python/Node/Chromium CI **0 failed、0 error**。运行缺失的测试必须明确记为 skipped，不能把 skipped 算通过。
- **工程门槛 B：** 在真实 Chromium 中至少分别执行桌面、手机操作，涵盖上传图片、点选、拖动、连边、反向箭头、重边、自环、缩放、子图框选、保存、重新打开；全部通过，无未处理 JS 错误。
- **工程门槛 C：** 10 张预设不同结构图（普通有向/无向、带权/无权、零权重、重边、自环、交叉但无节点、多幅子图、孤立点、无名点、曲线）进行编辑→确认→重开往返，节点/边/方向/权值/显示编号/坐标全相同。原图明显模糊时以人工最终核对后的结果为准。
- **AI 自动识别门槛：** 按前述已经冻结的 11 张清晰图 20 子图及阴影照片独立报告首次原图结果；当前**尚未**验证达到指标，不得将“用户能修”冒充 AI 达标。
- **不允许：** 为了让测试绿灯而删掉有效反例、放宽既有数据隔离或降低 100% 的编辑一致性标准；未经测试删除旧 CV 识别算法、直接合并 main、部署 Zeabur。
